# Задача 3. coalesce_updates — 6/10

Редактор отправляет изменения настроек пачкой. Одну настройку могли менять
несколько раз: сохранить нужно последнее значение, а применять настройки —
в порядке их **последних** обновлений.

Реализуйте
`coalesce_updates[T](updates: Iterable[tuple[str, T]]) -> OrderedDict[str, T]`
в файле `coalesce_updates.py`.

- Каждая пара — ключ настройки и новое значение. В результате ключ встречается
  один раз и хранит последнее значение.
- Порядок ключей совпадает с порядком последних появлений во входе. Даже
  повтор с тем же значением считается новым обновлением.
- Верните новый `OrderedDict`, чтобы получатель мог использовать
  `move_to_end()` и `popitem(last=False)`.
- Вход обходится один раз. Его нельзя сначала собрать в список или
  отсортировать. Пустой вход даёт пустой `OrderedDict`.
- Исходные коллекции не меняются; значения сохраняются по ссылке. Пустой
  ключ и значения `None`, `False`, `0`, `""` допустимы.
- Ошибки источника проходят наружу без замены. Время — `O(n)` в среднем,
  дополнительная память — `O(k)` для `k` разных ключей.

```python
result = coalesce_updates([
    ("theme", "light"),
    ("volume", 20),
    ("theme", "dark"),
    ("language", "ru"),
    ("volume", 30),
])
list(result.items())
# [("theme", "dark"), ("language", "ru"), ("volume", 30)]
result.popitem(last=False)       # ("theme", "dark")
```

Обычное присваивание существующему ключу не меняет его позицию ни в `dict`,
ни в `OrderedDict`. После каждого обновления явно перемещайте ключ в конец.
