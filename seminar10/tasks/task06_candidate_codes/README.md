# Задача 6. candidate_codes — 8/10

Генератор тестовых кодов должен учитывать два свойства: важен ли порядок
символов и можно ли повторно использовать одну позицию алфавита. Затем
нужно исключить запрещённые фрагменты и выдать первые подходящие результаты.
Пространство вариантов может быть огромным, поэтому строить его целиком нельзя.

Реализуйте в `candidate_codes.py`:

```python
def candidate_codes(
    alphabet: str, length: int, mode: Mode,
    forbidden: tuple[str, ...] = (), limit: int = 10,
) -> Iterator[str]: ...
```

Выберите функцию `itertools` по режиму:

| Режим | Порядок важен | Повторное использование позиции | Функция |
|---|---|---|---|
| `product` | да | да | `product(..., repeat=length)` |
| `permutations` | да | нет | `permutations(..., length)` |
| `combinations` | нет | нет | `combinations(..., length)` |
| `replacement` | нет | да | `combinations_with_replacement(..., length)` |

- Превращайте каждый кортеж символов в строку. Сохраняйте порядок выдачи
  выбранной функции: алфавит не сортируется.
- Отбрасывайте код, если хотя бы один элемент `forbidden` входит в него
  **как подстрока**, без изменения регистра. Пустая запрещённая подстрока
  отбрасывает любой код.
- Выдайте первые `limit` **подходящих** кодов. Фильтрация выполняется до
  ограничения. Когда лимит достигнут, продолжать перебор нельзя.
- При создании возвращаемого итератора перебор ещё не начинается.
  Не собирайте все кандидаты или подходящие ответы в список.
- При `length < 0`, `limit < 0` или неизвестном режиме первый запрос
  результата вызывает `ValueError`. Проверка параметров нужна и при `limit=0`.
- При нулевом лимите после проверки параметров не запускайте поиск.
- Длина ноль даёт один пустой код, если он не отфильтрован и лимит положителен.
  Пустой алфавит при положительной длине не даёт кодов. Невозможный выбор
  без повторений также даёт пустой результат.
- Одинаковые символы в разных позициях алфавита считаются разными элементами:
  одинаковые строки в ответе допустимы, устранять повторы через `set` нельзя.

```python
list(candidate_codes("BAC", 2, "combinations"))
# ["BA", "BC", "AC"] — порядок исходного алфавита

list(candidate_codes("AB", 3, "product", ("AA", "BB"), limit=2))
# ["ABA", "BAB"] — первые два подходящих, а не первые два кандидата

list(candidate_codes("AA", 2, "permutations"))  # ["AA", "AA"]
list(candidate_codes("AB", 0, "product"))       # [""]
```

Ограничение через `islice` ставится после ленивого фильтра. Оно ограничивает
число ответов, но не число проверенных кандидатов: если ничего не подходит,
может потребоваться полный перебор. Ленивость экономит память, но не отменяет
комбинаторного роста времени. `product` и другие комбинаторные функции
сохраняют входные элементы; здесь алфавит конечен.
