# Задача 5. tag_stream — 7/10

Сообщения приходят пакетами. Нужно передать первые `limit` сообщений одним
потоком, пронумеровать их и назначить метки по кругу. Границы пакетов не
сбрасывают ни номера, ни метки. Следующий пакет может ещё не быть доступен,
поэтому заранее получать его нельзя.

Реализуйте `tag_stream[T](batches: Iterable[Iterable[T]], labels: tuple[str, ...],
limit: int, start: int = 1) -> Iterator[Tagged[T]]` в `tag_stream.py`.

Класс `Tagged` с полями `number`, `label`, `value` уже объявлен. Это типизированный
вариант именованного кортежа: доступны имена полей, распаковка и сравнение с
обычным кортежем. Менять объявление класса не нужно.

- Обходите пакеты по очереди, а сообщения внутри пакета — в исходном порядке.
  Пустые пакеты пропускаются. Каждый источник обходится один раз.
- Номера идут от `start` с шагом один. Метки повторяются циклически; при пустом
  `labels` используйте пустую строку для каждого сообщения.
- Каждый ответ — `Tagged(number, label, value)`. Значение остаётся тем же
  объектом. Выдайте не более `limit` ответов.
- Вызов функции ничего не читает и не получает итератор внешнего источника.
  Для очередного ответа читается только необходимое следующее сообщение;
  чтобы найти его, могут потребоваться пустые пакеты.
- После выдачи `limit` ответов даже запрос конца не должен читать новое
  сообщение или получать следующий пакет. Внешний и внутренние источники
  могут быть бесконечными, если следующий нужный элемент достижим.
- При нулевом лимите источник вообще не запускается. При отрицательном
  первый запрос результата вызывает `ValueError` до запуска источника.
  Другие исключения источников проходят наружу без замены.
- Не собирайте пакеты или ответы в коллекции. Рабочая память — `O(len(labels))`.

Используйте `chain.from_iterable`, `islice`, `count`, `cycle` и `repeat`.
Последний нужен для случая без меток. Соединить номера, метки и сообщения
можно через `zip`; важно ограничивать именно поток сообщений.

```python
list(tag_stream([[10, 20], [], [30, 40]], ("a", "b", "c"), 3, start=0))
# [Tagged(number=0, label='a', value=10),
#  Tagged(number=1, label='b', value=20),
#  Tagged(number=2, label='c', value=30)]

list(tag_stream([["x", "y"]], (), 5))
# [Tagged(number=1, label='', value='x'), Tagged(number=2, label='', value='y')]
```

Бесконечный поток одних пустых пакетов не даёт следующего сообщения: задача
не требует определять это за конечное время. Ленивость выдачи также не означает,
что любой инструмент `itertools` использует нулевую память: `cycle` сохраняет
элементы своего источника, поэтому ему передаётся конечный набор меток.
