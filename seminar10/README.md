# Семинар 10. Collections, heapq и itertools

Шесть независимых задач по лекции 10. Сначала разбираемся, когда чтение
меняет контейнер и как связаны снимки с исходными объектами. Затем управляем
частотами, порядком и приоритетами. Последние две задачи собирают ленивые
конвейеры из инструментов `itertools`.

В каждом каталоге есть условие, заготовка и `test_public.py`. Реализуйте
объявленные функции и методы; тесты менять не нужно. Классы записей и псевдонимы
типов уже объявлены. Ни одна задача не импортирует решение другой.

## Задачи

1. **5/10 — [buckets](tasks/task01_buckets/README.md):** хранить независимые
   списки в `defaultdict`, просматривать отсутствующие ключи без их создания
   и возвращать поверхностные снимки.
2. **6/10 — [window_counts](tasks/task02_window_counts/README.md):** поддерживать
   частоты последних событий с помощью `deque` и `Counter`.
3. **6/10 — [coalesce_updates](tasks/task03_coalesce_updates/README.md):** оставить
   последнее значение каждого ключа и упорядочить ключи по последнему обновлению.
4. **7/10 — [priority_queue](tasks/task04_priority_queue/README.md):** реализовать
   очередь на `heapq`, сохраняя порядок поступления при одинаковом приоритете.
5. **7/10 — [tag_stream](tasks/task05_tag_stream/README.md):** лениво объединить
   пакеты, добавить номера и циклические метки, ограничить чтение.
6. **8/10 — [candidate_codes](tasks/task06_candidate_codes/README.md):** выбрать
   комбинаторный перебор и выдать первые подходящие коды после фильтрации.

На занятие в 90 минут можно взять задачи 1–4, а конвейеры 5–6 оставить
на продолжение.

## Проверка

Из корня репозитория:

```bash
uv run pytest seminar10/tasks/task01_buckets -v
uv run pytest seminar10/tasks/task02_window_counts -v
uv run pytest seminar10/tasks/task03_coalesce_updates -v
uv run pytest seminar10/tasks/task04_priority_queue -v
uv run pytest seminar10/tasks/task05_tag_stream -v
uv run pytest seminar10/tasks/task06_candidate_codes -v
```

Все задачи и проверки стиля:

```bash
uv run pytest seminar10/tasks -v
uv run ruff check seminar10
uv run mypy seminar10
```

Заготовки намеренно вызывают `NotImplementedError`: до решения задач проверки
поведения падают. Тесты проверяют результаты, независимость снимков, порядок
и момент чтения источников. Ограничение времени защищает от ошибочных
бесконечных циклов. Окружение устанавливается общей командой
`uv sync --extra test --extra lint`.

Требования к структуре данных и сложности проверяются также при просмотре
кода: поведенческий тест не может отличить все эквивалентные реализации.
