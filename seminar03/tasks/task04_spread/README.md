# Задача 4. spread — 8/10

Квадратное поле имеет размер `size × size`. Некоторые клетки заняты стенами, а
в некоторых находится вода. За один шаг вода остаётся в прежних клетках и
занимает соседние клетки по четырём сторонам: сверху, снизу, слева и справа.

По диагонали вода не распространяется. Она также не может попасть в стену или
выйти за границу поля.

Клетка представлена кортежем `(строка, столбец)`. Координаты начинаются с нуля
и заканчиваются числом `size - 1`.

```text
до шага              после шага
· · ·                 · o ·
· o ·        →        o o o
· · ·                 · o ·
```

Реализуйте функцию `spread`, которая возвращает состояние воды после одного
шага.

## Сигнатура

```python
Cell = tuple[int, int]


def spread(water: set[Cell], walls: set[Cell], size: int) -> set[Cell]: ...
```

## Требования

- все прежние клетки с водой входят в результат;
- `water` и `walls` не изменяются;
- результат является новым множеством, даже если вода не расширилась;
- `size` — положительное число;
- все переданные клетки находятся внутри поля;
- вода и стены изначально не пересекаются.

## Примеры

```python
spread({(1, 1)}, set(), 3)
# {(1, 1), (0, 1), (2, 1), (1, 0), (1, 2)}

spread({(0, 0)}, set(), 3)
# {(0, 0), (0, 1), (1, 0)}

spread({(0, 1)}, {(1, 1)}, 3)
# {(0, 0), (0, 1), (0, 2)}

spread({(1, 1)}, {(0, 1), (2, 1), (1, 0), (1, 2)}, 3)
# {(1, 1)}

spread({(0, 0), (0, 2)}, set(), 3)
# {(0, 0), (0, 1), (0, 2), (1, 0), (1, 2)}

spread(set(), set(), 4)
# set()
```
