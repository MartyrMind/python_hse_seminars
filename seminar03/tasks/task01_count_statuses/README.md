# Задача 1. count_statuses — 5/10

Сервис записывает состояния заданий в порядке их поступления: `"new"`,
`"running"`, `"done"`, `"failed"` и другие. Нужно построить сводку с числом
появлений каждого состояния.

Реализуйте функцию `count_statuses`. Она возвращает словарь, где ключ — строка
состояния, а значение — количество её появлений во входном списке.

## Сигнатура

```python
def count_statuses(statuses: list[str]) -> dict[str, int]: ...
```

## Требования

- состояния сравниваются с учётом регистра;
- пустая строка является допустимым состоянием;
- ключи результата идут в порядке первого появления состояний;
- исходный список не изменяется;
- для пустого списка результатом является пустой словарь.

## Примеры

```python
count_statuses(["new", "done", "new"])
# {"new": 2, "done": 1}

count_statuses(["failed", "new", "failed", "done", "new", "failed"])
# {"failed": 3, "new": 2, "done": 1}

count_statuses(["OK", "ok", "OK"])
# {"OK": 2, "ok": 1}

count_statuses(["", "ready", ""])
# {"": 2, "ready": 1}

count_statuses([])
# {}
```
