# Задача 5. typed_counts — 9/10

В потоке типизированных данных одинаково выглядящие значения могут иметь разный
смысл. Например, целое число `1`, логическое значение `True` и вещественное
число `1.0` нужно учитывать раздельно.

Реализуйте функцию `typed_counts`. Два элемента относятся к одной группе,
только если совпадают их точные типы и значения. Функция возвращает пары
`(первое значение группы, количество)` в порядке появления групп.

## Сигнатура

```python
Scalar = int | float | bool | str | None


def typed_counts(values: list[Scalar]) -> list[tuple[Scalar, int]]: ...
```

## Требования

- точный тип участвует в определении группы;
- представителем группы является первое встретившееся значение;
- группы идут в порядке первого появления;
- `None` является обычным допустимым значением;
- исходный список не изменяется;
- значения `float("nan")` во входных данных не встречаются.

## Примеры

```python
typed_counts(["new", "done", "new"])
# [("new", 2), ("done", 1)]

typed_counts([1, True, 1.0, 1, True])
# [(1, 2), (True, 2), (1.0, 1)]

typed_counts([0, False, 0.0])
# [(0, 1), (False, 1), (0.0, 1)]

typed_counts(["1", 1, "1"])
# [("1", 2), (1, 1)]

typed_counts([None, 0, None])
# [(None, 2), (0, 1)]

typed_counts([])
# []
```
