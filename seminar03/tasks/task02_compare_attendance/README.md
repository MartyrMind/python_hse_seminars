# Задача 2. compare_attendance — 6/10

Организаторы мероприятия получили два списка имён:

- `planned` — зарегистрированные участники;
- `actual` — люди, которые действительно пришли.

Реализуйте функцию `compare_attendance`, которая возвращает три списка:

1. зарегистрированные участники, которые пришли;
2. зарегистрированные участники, которые не пришли;
3. люди, которые пришли без регистрации.

## Сигнатура

```python
def compare_attendance(
    planned: list[str], actual: list[str]
) -> tuple[list[str], list[str], list[str]]: ...
```

## Требования

- каждый выходной список отсортирован по алфавиту;
- каждое имя встречается в своей группе не более одного раза;
- повторы имён во входных списках не влияют на результат;
- регистр имеет значение: `"Анна"` и `"анна"` — разные имена;
- исходные списки не изменяются.

## Примеры

```python
compare_attendance(
    ["Аня", "Борис", "Вера"],
    ["Борис", "Вера", "Глеб"],
)
# (["Борис", "Вера"], ["Аня"], ["Глеб"])

compare_attendance(["Яна", "Анна"], ["Анна", "Вера"])
# (["Анна"], ["Яна"], ["Вера"])

compare_attendance(["Аня", "Аня", "Борис"], ["Аня", "Аня"])
# (["Аня"], ["Борис"], [])

compare_attendance(["Анна"], ["анна"])
# ([], ["Анна"], ["анна"])

compare_attendance([], [])
# ([], [], [])

compare_attendance([], ["Аня"])
# ([], [], ["Аня"])
```
