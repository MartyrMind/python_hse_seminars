# Семинар 3. Контейнеры

Цель семинара — потренировать работу с контейнерами Python на задачах о
подсчёте, сравнении, группировке и хранении данных.

Каждая задача соответствует оценке, которую можно получить за семинар. Задачи
можно решать независимо, однако порядок подобран так, чтобы новые идеи
добавлялись постепенно.

## Задачи

1. **5/10 — [`count_statuses`](tasks/task01_count_statuses/README.md):** сводка
   по состояниям заданий.
2. **6/10 — [`compare_attendance`](tasks/task02_compare_attendance/README.md):**
   сравнение списков регистрации и посещения.
3. **7/10 — [`group_events`](tasks/task03_group_events/README.md):** группировка
   сообщений по виду события.
4. **8/10 — [`spread`](tasks/task04_spread/README.md):** один шаг распространения
   воды по полю.
5. **9/10 — [`typed_counts`](tasks/task05_typed_counts/README.md):** подсчёт
   значений с учётом их точных типов.
6. **10/10 — [`changes`](tasks/task06_changes/README.md):** отчёт об изменениях
   конфигурации.

## Проверка

Запустить все публичные тесты семинара:

```bash
uv run pytest seminar03/tasks -v
```

Пока задачи не решены, тесты завершаются с `NotImplementedError`. Это ожидаемо:
реализуйте выбранную функцию в её файле и повторите запуск для каталога задачи.
