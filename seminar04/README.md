# Семинар 4. Ссылки и копирование

Цель семинара — потренировать работу со ссылками, изменяемыми объектами,
копированием и вложенными структурами.

Каждая задача соответствует оценке, которую можно получить за семинар. Задачи
можно решать независимо, но их порядок постепенно переходит от одной общей
ссылки к целому графу объектов.

## Задачи

1. **5/10 — [`replace_contents`](tasks/task01_replace_contents/README.md):**
   заменить содержимое существующего списка.
2. **6/10 — [`make_board`](tasks/task02_make_board/README.md):** создать таблицу
   с независимыми строками.
3. **7/10 — [`order_records`](tasks/task03_order_records/README.md):** две версии
   упорядочивания записей.
4. **8/10 — [`remove_exact`](tasks/task04_remove_exact/README.md):** удалить
   конкретный объект из списка.
5. **9/10 — [`restore_playlist`](tasks/task05_restore_playlist/README.md):**
   сохранить и восстановить плейлист.
6. **10/10 — [`total_size`](tasks/task06_total_size/README.md):** посчитать
   полный размер вложенной структуры.

## Проверка

```bash
uv run pytest seminar04/tasks -v
```

Пока задачи не решены, тесты завершаются с `NotImplementedError`. Реализуйте
выбранные функции в их файлах и запустите тесты соответствующего каталога.
