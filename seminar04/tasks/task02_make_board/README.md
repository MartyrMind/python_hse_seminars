# Задача 2. make_board — 6/10

Игровое поле представлено списком строк, а каждая строка — списком целых чисел.

Реализуйте функцию `make_board`, которая создаёт поле размера `rows × cols` и
заполняет каждую клетку числом `fill`.

## Сигнатура

```python
def make_board(rows: int, cols: int, fill: int = 0) -> list[list[int]]: ...
```

## Требования

- в результате ровно `rows` строк;
- в каждой строке ровно `cols` элементов;
- каждая строка является отдельным объектом;
- изменение клетки одной строки не меняет другие строки;
- `rows` и `cols` неотрицательны, проверять их не нужно.

## Примеры

```python
make_board(2, 3)
# [[0, 0, 0], [0, 0, 0]]

make_board(2, 3, 7)
# [[7, 7, 7], [7, 7, 7]]

make_board(0, 4)
# []

make_board(2, 0)
# [[], []]

make_board(1, 1, -3)
# [[-3]]
```

Строки должны оставаться независимыми после создания:

```python
board = make_board(3, 3)
board[0][1] = 5

board
# [[0, 5, 0],
#  [0, 0, 0],
#  [0, 0, 0]]

board[0] is board[1]  # False
```
