# Семинар 9. Итераторы и генераторы

Первые три задачи посвящены получению элементов и состоянию собственного
итератора. Четвёртая показывает приостановку генератора между двумя выдачами
одного элемента. В пятой генератор принимает ответы и исключения, а в шестой
передаёт этот обмен вложенному генератору через `yield from`.

Задачи независимы: ни одна не импортирует решение другой. В каждом каталоге
есть условие, заготовка реализации и `test_public.py`. Реализуйте объявленные
функции и методы; тесты менять не нужно.

## Задачи

1. **5/10 — [same_values](tasks/task01_same_values/README.md):** сравнить два
   источника за один проход и остановиться на первом различии.
2. **6/10 — [peekable](tasks/task02_peekable/README.md):** реализовать итератор
   с просмотром следующего элемента и буфером на один элемент.
3. **7/10 — [call_iterator](tasks/task03_call_iterator/README.md):** самостоятельно
   построить итератор над вызываемым источником с сигналом остановки.
4. **7/10 — [echo_each](tasks/task04_echo_each/README.md):** выдавать каждый
   входной элемент дважды, сохраняя ленивость и состояние между `yield`.
5. **8/10 — [dialogue](tasks/task05_dialogue/README.md):** принимать ответы
   через `send`, повторять вопрос через `throw` и завершать работу с `finally`.
6. **9/10 — [relay](tasks/task06_relay/README.md):** делегировать вложенному
   генератору выдачу, ответы, исключения и закрытие, сохраняя результат `return`.

## Проверка

Из корня репозитория:

```bash
uv run pytest seminar09/tasks/task01_same_values -v
uv run pytest seminar09/tasks/task02_peekable -v
uv run pytest seminar09/tasks/task03_call_iterator -v
uv run pytest seminar09/tasks/task04_echo_each -v
uv run pytest seminar09/tasks/task05_dialogue -v
uv run pytest seminar09/tasks/task06_relay -v
```

Все задачи семинара:

```bash
uv run pytest seminar09/tasks -v
uv run ruff check seminar09
uv run mypy seminar09
```

Тесты проверяют и результаты, и момент чтения источника. Правильный список,
полученный с преждевременным чтением всех данных, не выполняет условие.
Заготовки намеренно вызывают `NotImplementedError`, поэтому до решения задач
проверки поведения падают. Ограничение времени защищает от зависания
ошибочных бесконечных циклов; окружение устанавливается общей командой
`uv sync --extra test --extra lint`.
