# Задача 4. echo_each — 7/10

Поток уведомлений нужно передать дважды: сначала основному получателю, затем
резервному. Каждый элемент читается из источника один раз, но выдаётся два
раза подряд. Весь поток заранее неизвестен и может быть бесконечным.

Реализуйте генераторную функцию
`echo_each[T](source: Iterable[T]) -> Iterator[T]` в файле `echo_each.py`.

- Каждый элемент источника выдаётся дважды подряд в исходном порядке.
- Возвращаемый объект — настоящий генератор; используйте `yield`.
- При вызове функции источник ещё не запускается: даже `iter(source)` должен
  вызываться только при первом запросе результата.
- Для первого ответа читается первый элемент источника. Для второго ответа
  он используется повторно без нового чтения. Третий ответ требует второго
  элемента, и так далее.
- Выдавайте тот же объект, а не его копию. `None` и ложные значения допустимы.
- Источник обходится один раз; дополнительная память — `O(1)`.
- Ошибки источника проходят наружу без замены в тот момент, когда требуется
  очередное чтение. Не вызывайте `StopIteration` вручную внутри генератора:
  нормальное завершение тела само завершает перебор.

```python
list(echo_each([1, 2, 3]))        # [1, 1, 2, 2, 3, 3]
list(echo_each([]))              # []

source = iter([10, 20, 30])
walk = echo_each(source)
next(walk)                      # 10 — прочитан первый элемент source
next(walk)                      # 10 — новых чтений нет
next(walk)                      # 20 — прочитан второй элемент source
next(source)                    # 30
```

В примере последнее действие читает источник напрямую, поэтому дальнейший
обход `walk` уже не обязан увидеть `30`. Генератор хранит текущий элемент,
но не создаёт независимый обход входного итератора.
