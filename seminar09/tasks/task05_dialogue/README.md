# Задача 5. dialogue — 8/10

Форма знакомства задаёт два вопроса. Ответ приходит снаружи, а форма помнит,
на каком вопросе остановилась. Если пользователь просит повторить текущий
вопрос, уже принятые ответы сохраняются.

В файле `dialogue.py` дан класс исключения `RetryQuestion`. Не меняйте его.
Реализуйте `dialogue(events: list[str]) -> Generator[str, str, None]`.

1. Вызов функции только создаёт генератор, не меняя `events`.
2. Первый `next()` добавляет `"started"` в `events` и выдаёт `"Имя?"`.
3. `send(name)` принимает имя и выдаёт `"Город?"`.
4. `send(city)` принимает город и выдаёт `f"Привет, {name} из {city}!"`.
   Строки используются как есть, включая пустые строки и пробелы.
5. После приветствия генератор остаётся приостановленным на последнем `yield`.
   Следующий `next()` или `send(...)` завершает его, не выдавая новых значений.
   Возвращаемое значение генератора — `None`.
6. `throw(RetryQuestion())` во время любого из двух вопросов повторно выдаёт
   **тот же вопрос**, не принимая новый ответ и не теряя предыдущие ответы.
   После приветствия это исключение уже не обрабатывается.
7. Любое другое исключение проходит наружу без замены и завершает генератор.
8. В `finally` добавьте `"finished"` ровно один раз. Он должен выполниться при
   нормальном завершении, необработанном исключении и `close()` после запуска.
   Закрытие ещё не запущенного генератора не выполняет его тело: `events`
   остаётся пустым.

`events` содержит только `"started"` и `"finished"`; вопросы и ответы туда
не записываются. Используйте выражение `answer = yield question`, чтобы
получить ответ, и обработку `RetryQuestion` вокруг ожидания ответа. Можно
добавлять вспомогательные функции, но другие задачи импортировать не нужно.

```python
events = []
form = dialogue(events)
events                              # []
next(form)                          # "Имя?"
form.throw(RetryQuestion())          # "Имя?"
form.send("Аня")                    # "Город?"
form.throw(RetryQuestion())          # "Город?"
form.send("Москва")                 # "Привет, Аня из Москва!"
events                              # ["started"]
next(form)                          # StopIteration
events                              # ["started", "finished"]
```

Грамматическое склонение города не требуется. До первого `yield` нельзя
передать непустой ответ: сначала вызовите `next(form)` или `form.send(None)`.
Здесь `send(None)` используется только для начального запуска; при передаче
ответов считайте, что приходят строки. После приветствия для завершения можно
использовать обычный `next()`.
