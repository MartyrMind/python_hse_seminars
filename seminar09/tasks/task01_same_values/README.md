# Задача 1. same_values — 5/10

Два сервиса выгружают записи по одной. Нужно проверить, совпадают ли выгрузки,
но сохранить их целиком в памяти нельзя. Источник может быть одноразовым
итератором, у которого нет длины и доступа по индексу.

Реализуйте `same_values(left: Iterable[Any], right: Iterable[Any]) -> bool`
в файле `same_values.py`.

- Получите по одному итератору для каждого источника. Повторный обход не нужен.
- На каждом шаге запросите сначала элемент слева, затем элемент справа.
  Даже если слева уже конец, справа нужно сделать запрос, чтобы сравнить длины.
- Если оба источника закончились на этом шаге, верните `True`.
- Если закончился только один или очередные элементы не равны через `==`,
  верните `False`. После обнаруженного различия больше ничего не запрашивайте.
- `None`, `False`, `0` и пустая строка — обычные значения, а не признаки конца.
- Ошибки получения итератора, чтения и сравнения элементов, кроме
  `StopIteration` при чтении, должны пройти наружу без замены.
- Дополнительная память — `O(1)`. Не собирайте источники в коллекции.

Используйте `iter()` и `next()`. Для отличия конца от любого допустимого
значения можно создать собственный сторожевой объект: `missing = object()`.
Его нужно распознавать через `is`, а не через сравнение с данными.

```python
same_values([1, None, 3], iter([1, None, 3]))  # True
same_values([1, 2], [1, 2, 3])               # False
same_values([], [])                         # True

left = iter([1, 7, 100])
right = iter([1, 8, 200])
same_values(left, right)                    # False
next(left), next(right)                     # (100, 200)
```

Источники расходуются: функция продолжает с их текущего положения. Их
независимость не создаётся автоматически. Если передать один и тот же итератор
в оба аргумента, два запроса на шаге будут обращаться к одному общему обходу.
Два бесконечных равных источника сравниваются бесконечно; тесты не требуют
определять их равенство за конечное время.
