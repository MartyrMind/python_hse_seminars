# Задача 2. load_pages — 7/10

Склад забирает строки из постраничного сервиса. Следующую страницу получают по
курсору, который вернула предыдущая. У сервиса есть основной (`primary`) и
резервный (`reserve`) узлы. Оба понимают одни и те же курсоры.

В заготовке дан класс `Page`: `rows` — строки страницы, `next_cursor` — курсор
следующей страницы или `None`, если страниц больше нет. Каждый источник —
функция `fetch(cursor) -> Page`. Переданная функция `save_all(rows)` сохраняет
весь список атомарно: если она сама завершится ошибкой, частично сохранённых
данных не останется.

Реализуйте `PageLoadError` и `load_pages(n, start_cursor, primary, reserve,
save_all) -> list[str]`.

- `n` должно быть положительным. Иначе поднимите `ValueError` до любых вызовов
  источников или сохранения.
- Запросите ровно `n` страниц, начиная с `start_cursor`. Соберите строки в
  порядке страниц и строк внутри каждой страницы.
- Если `primary` выбросил `ConnectionError` или `TimeoutError`, запросите эту
  же страницу у `reserve` с тем же курсором. После переключения все следующие
  страницы запрашивайте только у `reserve`.
- Любое другое исключение типа `Exception` из `primary` и любое такое
  исключение из `reserve`, включая ошибки соединения, превратите в
  `PageLoadError` через `raise ... from ...`. Не перехватывайте
  `KeyboardInterrupt` и `SystemExit`.
- Если `next_cursor` равен `None` до получения всех `n` страниц, поднимите
  `PageLoadError`. Ответ последней нужной страницы может иметь любой
  `next_cursor`.
- `PageLoadError` хранит `source` (`"primary"` или `"reserve"`), `page_number`
  (с единицы) и `cursor` неудачного запроса. При преждевременном конце страниц
  эти поля относятся к последней полученной странице, а `__cause__` равен `None`.
- Вызовите `save_all` ровно один раз после получения всех страниц, затем
  верните собранные строки. При любой ошибке загрузки `save_all` не вызывается.
  Ошибка самой `save_all` проходит наружу без замены.

Каждый запрос страницы либо возвращает целый `Page`, либо выбрасывает
исключение; частично полученных страниц не бывает. Источники при успешном
вызове возвращают корректные экземпляры `Page`.

```python
# primary(None) -> Page(["ручка;2"], "c1")
# primary("c1") -> TimeoutError
# reserve("c1") -> Page(["карандаш;3"], "c2")
# reserve("c2") -> Page(["линейка;1"], None)
# load_pages(3, None, primary, reserve, save_all)
# -> ["ручка;2", "карандаш;3", "линейка;1"]
# save_all вызвана один раз с этим списком.
```

В этой задаче строки страниц не разбираются: `load_pages` не зависит от
`parse_stock_row` из задачи 1.
