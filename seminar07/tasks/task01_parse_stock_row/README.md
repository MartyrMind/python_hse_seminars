# Задача 1. parse_stock_row — 6/10

Склад получает строки вида `название;количество`. Напишите функцию
`parse_stock_row(raw: str) -> tuple[str, int] | None`, которая возвращает пару
из названия товара и количества. Непригодная строка даёт `None`.

- Разделитель — ровно одна точка с запятой. Строка без неё или с несколькими
  точками с запятой непригодна.
- Пробелы по краям обеих частей удаляются. Название после этого должно быть
  непустым и не содержать запятую: запятая оставлена для старого формата данных.
- Количество преобразуется стандартным `int(...)` и должно быть больше нуля.
  Допустимы все записи, которые принимает `int`, например `+2` и `002`.
- Функция ничего не печатает. Аргумент `raw` по контракту всегда строка.

Обработайте только ожидаемую ошибку преобразования числа. Успешное продолжение
можно вынести в `else` блока `try`; граница `try` должна оставаться узкой.

```python
parse_stock_row("карандаш;12")           # ("карандаш", 12)
parse_stock_row(" цветной карандаш ; 002 ")  # ("цветной карандаш", 2)
parse_stock_row("ручка;+3")              # ("ручка", 3)
parse_stock_row("ручка;три")             # None
parse_stock_row("ручка;0")               # None
parse_stock_row("ручка;2;склад")         # None
```
