# Задача 3. build_exception_tree — 8/10

После загрузки нескольких операций система получила список исключений. Для
отчёта нужно построить дерево, которое показывает состав групп, видимые связи
между ошибками и места, где они возникли. Сами исключения уже созданы: разбирать
строки и вызывать операции в этой задаче не требуется.

В заготовке дан `ErrorNode` с полями:

- `error` — исходный объект исключения;
- `frames` — список кадров собственного traceback этого исключения;
- `children` — список пар `(тип_связи, дочерний_узел)`, где тип связи равен
  `"member"`, `"cause"` или `"context"`.

Реализуйте `build_exception_tree(errors: list[Exception]) -> ErrorNode`.

1. Пустой список отвергайте через `ValueError`. Для непустого списка создайте
   корень `ExceptionGroup("Ошибки операций", errors)`. Объекты из `errors` должны
   остаться теми же и в том же порядке.
2. Для каждого `ExceptionGroup` и вложенного `BaseExceptionGroup` сначала
   добавьте по одному потомку `"member"` для каждого элемента `.exceptions` в
   исходном порядке. Группы раскрываются рекурсивно.
3. После элементов группы для любого исключения добавьте связь `"cause"`, если
   `__cause__` не равен `None`. Иначе добавьте связь `"context"`, если
   `__context__` не равен `None` и `__suppress_context__` ложен. Если контекст
   подавлен, не показывайте его, даже когда `__cause__` равен `None`. На каждом
   следующем узле действуют те же правила.
4. Для `frames` используйте `traceback.extract_tb(error.__traceback__)`:
   храните список `FrameSummary`, а не живые кадры или сам traceback. Если
   исключение не поднимали, список пуст.
5. Если одна и та же ошибка встретилась **повторно на текущем пути** дерева,
   сохраните ребро и узел с этой ошибкой, но оставьте его `children` пустым.
   Если ошибка встретилась в разных ветвях, раскрывайте её в каждой ветви.
   Определяйте повтор по идентичности объекта, а не по тексту ошибки.

Не меняйте переданные объекты исключений и их служебные атрибуты.
```python
source = OSError("сеть")
failure = RuntimeError("загрузка")
failure.__cause__ = source

root = build_exception_tree([failure])
# root.children[0] -> ("member", узел failure)
# root.children[0][1].children[0] -> ("cause", узел source)
```
