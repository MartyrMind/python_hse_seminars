0:45–2:00 · Связать с опытом студентов. Покажите вложенность в каждом примере. Форма данных разная, но вопрос один: «Кто здесь родитель, а кто его дети?» HTML-схема упрощена до элементов. 02 / Минимум терминов

Обойти = посетить каждую вершину

Например, вывести имя, посчитать размер или найти нужный элемент.

Корень — AС него начинаем обход.
Дети A — B и CРёбра соединяют родителя с детьми.
Листья — G, E и FУ них нет детей.
Глубина — число рёбер от корняУ A — 0, у G — 3.

Договоримся: детей рассматриваем слева направо. У каждой вершины, кроме корня, один родитель; циклов нет.

2:00–3:00 · Задать правила. Вершина — это наш объект, ребро — связь с его частью. Посетить здесь означает выполнить действие один раз, а не только пройти по ребру. Фиксируем порядок детей, иначе разные корректные обходы могут дать разные последовательности. DFS и BFS — две базовые стратегии; у DFS есть варианты. Далее показываем DFS с посещением вершины до её детей.

03 / Depth-first search

DFS: сначала в глубину

Идём в первую ветку до конца. Затем возвращаемся к оставшимся.

текущаяпосещенаожидает

Один шаг — одна посещённая вершина

Порядок посещения
Стек · следующая вершина слева

Стек: последний вошёл — первый вышел.
Чтобы B был раньше C, кладём в стек C, затем B.

3:00–4:40 · Пройти вместе. Нажимайте «Шаг». После A спросите, кто дальше. После D остановитесь: идём к G, хотя C гораздо ближе к корню. В G детей нет, следующая отложенная ветка — E. Получится A, B, D, G, E, C, F. Здесь показан явный стек ожидающих вершин. В рекурсивном DFS ту же стратегию поддерживает стек вызовов: это другой способ реализации.

04 / Breadth-first search

BFS: сначала в ширину

Посещаем весь текущий уровень, затем переходим на следующий.

текущаяпосещенаожидает

То же дерево, другое правило

Порядок посещения
Очередь · следующая вершина слева

Очередь: первый вошёл — первый вышел.
Детей добавляем в конец очереди.

4:40–6:20 · Подчеркнуть отличие. После B в очереди C, D, E. Новые дети не обгоняют тех, кто уже ждал. Получится A, B, C, D, E, F, G. Спросите: «Почему G теперь последний?» Его глубина больше. Можно провести аналогию с очередью в столовой: пришедшие позже встают в конец.

05 / От картинки к Python

За обходом — короткое правило

children[v] — список детей вершины v.

DFS / рекурсия

def dfs(v):
    print(v)
    for child in children[v]:
        dfs(child)

dfs("A")
# A B D G E C F

Функция вызывает себя для каждого ребёнка.
Вернуться назад помогает стек вызовов.

BFS / очередь

from collections import deque

queue = deque(["A"])
while queue:
    v = queue.popleft()
    print(v)
    queue.extend(children[v])
# A B C D E F G

Берём вершину из начала очереди.
Её детей добавляем в конец.

children = {"A": ["B", "C"], "B": ["D", "E"], "C": ["F"],
            "D": ["G"], "E": [], "F": [], "G": []}
6:20–7:50 · Прочитать только главное. Сначала определяется словарь children, затем запускается любой из двух фрагментов. Пустой список детей завершает ветку рекурсии без отдельного if. Не разбирайте синтаксис построчно: в DFS важно «обработать ребёнка целиком», в BFS — «поставить детей в очередь». Для очень глубоких деревьев в Python используют явный стек, чтобы не упереться в ограничение глубины рекурсии.

06 / Выбираем под задачу

Что хочется получить первым?

DFS · СТЕК / РЕКУРСИЯ

Целую ветку

Удобно исследовать вложенную структуру или перебирать варианты с возвратом.

Например: обработать содержимое одной папки, затем перейти к соседней.

BFS · ОЧЕРЕДЬ

Ближайшую вершину

Первое совпадение будет на минимальной глубине — в числе рёбер от корня.

Например: найти ближайший к корню элемент, подходящий под условие.

Если нужно посетить всё дерево, оба обхода займут O(n): каждую из n вершин посещаем один раз.*

* При постоянной стоимости действия в вершине. Для графов с циклами нужен учёт посещённых вершин; BFS даёт кратчайший путь по числу рёбер.

7:50–9:10 · Объяснить смысл выбора. Если подходят и F, и G, DFS в нашем порядке раньше найдёт G, BFS — F: у F глубина 2, у G — 3. Кратчайший путь здесь значит минимум рёбер, а не минимальную сумму произвольных весов. Оба обхода могут найти любой существующий элемент. Для рекурсивного DFS дополнительная память — O(h) на стек вызовов, для BFS — O(w) на очередь по максимальной ширине; оба в худшем случае O(n). Не переносите O(h) автоматически на любой вариант явного стека. Эти детали можно оставить для вопросов.

07 / Проверяем интуицию

Кого посетим следующим?

DFS уже посетил A → B → D.
Кто следующий?

BFS уже посетил A → B.
Кто следующий?

DFS → G. Продолжаем в глубину.
BFS → C. Завершаем уровень.

DFS — ветка за веткой.
BFS — уровень за уровнем.

9:10–10:00 · Дать ответить аудитории. Выдержите паузу до показа ответа. Финальная мысль: «Как только заметили вложенную структуру, можно отделить действие над объектом от порядка обхода». Двух стратегий достаточно для первого знакомства; варианты DFS и обходы произвольных графов — темы на будущее.
