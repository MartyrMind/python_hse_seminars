# Семинар 6. Классы и специальные методы

Цель семинара — потренировать работу с методами классов, вызываемыми объектами,
свойствами, сравнением, хешированием и наследованием.

Каждая задача соответствует оценке, которую можно получить за семинар. Задачи
можно решать независимо, но их порядок постепенно переходит от одного метода
к взаимодействию нескольких классов.

## Задачи

1. **5/10 — [`message_factory`](tasks/task01_message_factory/README.md):**
   создать сообщение нужного класса через общую фабрику.
2. **6/10 — [`last_call_cache`](tasks/task02_last_call_cache/README.md):**
   запомнить результат последнего вызова функции.
3. **7/10 — [`window`](tasks/task03_window/README.md):** изменять границы
   интервала с проверкой их порядка.
4. **8/10 — [`participant`](tasks/task04_participant/README.md):** использовать
   участника с изменяемым именем как ключ словаря.
5. **9/10 — [`affine`](tasks/task05_affine/README.md):** определить вызов и
   умножение линейных преобразований со сдвигом.
6. **10/10 — [`cooperative_job`](tasks/task06_cooperative_job/README.md):**
   согласовать конструкторы при множественном наследовании.

## Проверка

```bash
uv run pytest seminar06/tasks -v
```

Пока задачи не решены, тесты завершаются с `NotImplementedError`. Реализуйте
выбранные методы в их файлах и запустите тесты соответствующего каталога.
