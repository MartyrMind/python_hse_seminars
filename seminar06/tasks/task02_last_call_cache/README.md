# Задача 2. last_call_cache — 6/10

Напишите `LastCallCache(func)`. Полученный объект вызывается с одним целым
числом. Если оно равно аргументу предыдущего вызова, возвращается тот же объект
результата без выполнения `func`. Иначе функция выполняется, а запомненный
вызов заменяется новым.

При создании кеша функция не выполняется. Её результат может быть любым,
включая `None`; она всегда завершается нормально. Кеши разных экземпляров
независимы.

```python
calls = []


def calculate(x):
    calls.append(x)
    return x * 2


cached = LastCallCache(calculate)
cached(5)  # 10
cached(5)  # 10
cached(7)  # 14
cached(5)  # 10
calls  # [5, 7, 5]
```
