# Задача 2. last_call_cache — 6/10

Функцию иногда несколько раз подряд вызывают с одинаковыми аргументами.
Реализуйте класс `LastCallCache`: его экземпляр вызывается как функция и
запоминает результат только последнего вызова.

## Интерфейс

```python
from collections.abc import Callable
from typing import Any


class LastCallCache:
    def __init__(self, func: Callable[..., Any]) -> None: ...
    def __call__(self, /, *args: Any, **kwargs: Any) -> Any: ...
```

## Требования

- создание объекта не вызывает `func`;
- первый вызов передаёт аргументы в `func` и сохраняет результат;
- если кортеж позиционных аргументов и словарь именованных равны аргументам
  последнего вызова, возвращается сохранённый результат без выполнения `func`;
- иначе функция выполняется заново, а сохранённый вызов заменяется;
- порядок именованных аргументов на сравнение не влияет;
- способы передачи параметра не объединяются: `cached(5)`, `cached(x=5)` и
  `cached()` считаются разными вызовами, даже если у функции есть `x=5`;
- `None`, `0`, `False` и другие ложные результаты тоже запоминаются;
- при повторе возвращается тот же объект результата, без копирования;
- разные экземпляры кеша не разделяют состояние.

Аргументы в тестах — целые числа, вещественные числа и строки. Функция может
возвращать любой объект, но всегда завершается нормально и не вызывает сам
кеш повторно из своего тела. Проверять типы аргументов не требуется.
Разделитель `/` в `__call__` оставляет имя `self` доступным в `**kwargs`.

## Примеры

```python
calls = []


def calculate(x, *, scale=1):
    calls.append((x, scale))
    return x * scale


cached = LastCallCache(calculate)
calls  # []
cached(5, scale=2)  # 10
cached(5, scale=2)  # 10, без нового выполнения calculate
cached(7, scale=2)  # 14
cached(5, scale=2)  # 10, calculate выполняется снова
calls  # [(5, 2), (7, 2), (5, 2)]
```

```python
cached = LastCallCache(lambda value: [value])
result = cached(1)
result.append(99)
cached(1) is result  # True
cached(1)  # [1, 99]
cached(2)  # [2]
```
