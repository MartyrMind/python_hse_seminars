# Задача 5. frozen_key — 9/10

Список или словарь нельзя использовать ключом словаря. Напишите `FrozenKey(data)`,
который сохраняет содержимое вложенных данных на момент создания и может быть
ключом. Два таких ключа равны, если сохранённые данные равны по обычным правилам
Python: порядок элементов списка важен, порядок записей словаря — нет.

Изменение исходных данных не должно менять ключ. Данные состоят из целых чисел,
строк, списков и словарей со строковыми ключами; циклических ссылок нет.
Готовые средства сериализации (`json`, `pickle` и подобные) не используются.

```python
data = {"scores": [3, 5], "name": "Аня"}
key = FrozenKey(data)
results = {key: "готово"}

data["scores"].append(9)
results[FrozenKey({"name": "Аня", "scores": [3, 5]})]  # "готово"
key == FrozenKey(data)  # False

FrozenKey([]) == FrozenKey({})  # False
```
