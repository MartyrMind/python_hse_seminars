# Задача 4. tile — 8/10

У квадратной плитки окрашены четыре стороны. `Tile(colors)` получает кортеж
из четырёх строк: цвета сверху, справа, снизу и слева.

Плитки считаются равными, если одну можно повернуть и совместить с другой.
Переворачивать плитку зеркально нельзя. Напишите класс, чтобы множество
плиток оставляло по одному представителю каждого вида.

Цвета могут повторяться. После создания плитка не меняется; методы поворота
или редактирования не нужны. Входные кортежи всегда корректны.

```python
a = Tile(("a", "b", "c", "d"))
b = Tile(("c", "d", "a", "b"))
mirror = Tile(("a", "d", "c", "b"))

a == b  # True
a == mirror  # False
len({a, b, mirror})  # 2
```
