# Задача 3. window — 7/10

Интервал задаётся двумя целыми границами. Левая граница не должна быть больше
правой. Реализуйте класс `Window(start, stop)`, который сохраняет это условие
при создании и последующих изменениях.

## Интерфейс

- `start` и `stop` — свойства с чтением и записью;
- `length` — свойство только для чтения, равное `stop - start`;
- `move(delta)` — сдвигает обе границы на целое `delta` и возвращает `None`.

В заготовке свойства объявлены через `property`, как в лекции. Реализуйте
конструктор, функции чтения и записи свойств и метод `move`.

## Требования

- всегда выполняется `start <= stop`, равные границы допустимы;
- некорректные границы в конструкторе вызывают `ValueError`;
- недопустимая запись в свойство вызывает `ValueError` и не меняет объект;
- `length` вычисляется при чтении, отдельно хранить её не нужно;
- сдвиг работает для положительных, отрицательных и нулевых значений;
- сдвиг сохраняет длину и меняет существующий объект;
- все входные значения — целые числа, проверять типы не требуется.

## Примеры

```python
w = Window(10, 20)
w.start = 15
w.length  # 5

w.move(100)
(w.start, w.stop)  # (115, 120)
w.move(-200)
(w.start, w.stop)  # (-85, -80)
```

Следующие попытки записи выполняются по отдельности:

```python
w = Window(10, 20)
w.stop = 5  # ValueError
(w.start, w.stop, w.length)  # (10, 20, 10), состояние сохранено

w.length = 99  # AttributeError
Window(20, 10)  # ValueError
Window(5, 5).length  # 0
```

Перед реализацией найдите корректный сдвиг, при котором такой код завершится
ошибкой:

```python
self.start += delta
self.stop += delta
```

Проверьте, решает ли перестановка этих строк проблему для обоих направлений.
Допускается любой способ сдвига, который выполняет требования задачи.
