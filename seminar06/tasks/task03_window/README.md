# Задача 3. window — 7/10

Напишите `Window(start, stop)`. Границы можно менять присваиванием, но начало
не должно оказаться правее конца. Недопустимые границы вызывают `ValueError`,
а отклонённая запись сохраняет прежнее состояние объекта.

Атрибут `length` показывает текущую длину и доступен только для чтения.
Метод `move(delta)` сдвигает обе границы на `delta`, меняет существующий объект
и возвращает `None`. Все числа целые, равные границы допустимы.

```python
w = Window(10, 20)
w.start = 15
w.length  # 5

w.move(100)
(w.start, w.stop)  # (115, 120)
w.move(-200)
(w.start, w.stop)  # (-85, -80)

w.stop = -100  # ValueError; границы остаются (-85, -80)
```
