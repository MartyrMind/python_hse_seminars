# Задача 5. affine — 9/10

Преобразование `f(x) = a * x + b` умножает число на коэффициент и добавляет
сдвиг. Реализуйте класс `Affine(a, b)`, экземпляр которого можно вызывать как
функцию и умножать на другие преобразования и целые числа.

Конструктор уже написан: коэффициенты хранятся в полях `a` и `b`.

## Вызов и умножение

- `f(x)` возвращает `f.a * x + f.b`;
- `f * g` означает композицию: сначала применяется `g`, затем `f`;
- целое число `k` в умножении означает преобразование `x → k * x`;
- поэтому `(f * k)(x) == f(k * x)`, а `(k * f)(x) == k * f(x)`.

Реализуйте `__call__`, `__mul__` и `__rmul__`.

## Требования

- результат умножения — новый `Affine` с коэффициентами итогового преобразования;
- исходные объекты не меняются и не разделяют состояние с результатом;
- это верно и при умножении на `1` или на самого себя;
- неподдерживаемый операнд даёт `NotImplemented` из соответствующего метода;
- не нужно самостоятельно возбуждать `TypeError`: при отсутствии подходящей
  реализации это делает Python;
- коэффициенты, аргумент `x` и множитель `k` — целые числа; `bool` и наследники
  `Affine` в задаче не рассматриваются.

## Примеры

```python
f = Affine(2, 1)
g = Affine(1, 10)

f(3)  # 7
(f * g)(3)  # f(g(3)) = 27
(g * f)(3)  # g(f(3)) = 17

(f * 3)(4)  # f(12) = 25
(3 * f)(4)  # 3 * f(4) = 27

(f * 0)(4)  # 1
(0 * f)(4)  # 0
```

```python
result = f * g
(result.a, result.b)  # (2, 21)
result is f  # False
result is g  # False

f.a = 100
result(3)  # 27, коэффициенты результата уже вычислены
```

```python
f.__mul__("text") is NotImplemented  # True
f.__rmul__(1.5) is NotImplemented  # True
f * "text"  # TypeError
```
