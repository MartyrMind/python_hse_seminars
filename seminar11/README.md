# Семинар 11. Замыкания и декораторы

В каждом каталоге есть условие, типизированная заготовка и `test_public.py`.
Реализуйте объявленные функции и методы. Тесты и готовые объявления
`Protocol` менять не нужно.

## Задачи

1. **4/10 — [trimmed](tasks/task01_trimmed/README.md):** удалить пробельные
   символы по краям результата функции.
2. **6/10 — [batched](tasks/task02_batched/README.md):** разбить вход на пакеты,
   вызвать функцию для каждого пакета и объединить результаты.
3. **6/10 — [retry](tasks/task03_retry/README.md):** повторять операцию при
   определённых ошибках, прекращая попытки при первом успехе.
4. **9/10 — [LRUMemo](tasks/task04_lru_memo/README.md):** кэшировать результаты
   функции с ограничением числа записей и вытеснением по давности обращения.
5. **10/10 — [transactional](tasks/task05_transactional/README.md):** выполнять
   изменения словаря с вложенными точками сохранения и откатом при ошибках.

## Общие требования

- Декорирование не вызывает исходную функцию.
- Аргументы и результаты не копируются, кроме преобразований, указанных
  в условии задачи. Исключения передаются наружу без замены.
- Используйте `functools.wraps`. У обёртки сохраняются имя, полное имя,
  модуль, документация, аннотации, параметры типов и пользовательские
  атрибуты исходной функции. `__wrapped__` ссылается на функцию, переданную
  этому декоратору, в том числе при нескольких слоях обёрток.
- Декорируются обычные синхронные функции. Генераторные и асинхронные
  функции, методы классов и многопоточность в задания не входят.

## Проверка

Из корня репозитория:

```bash
uv run pytest seminar11/tasks/task01_trimmed -v
uv run pytest seminar11/tasks/task02_batched -v
uv run pytest seminar11/tasks/task03_retry -v
uv run pytest seminar11/tasks/task04_lru_memo -v
uv run pytest seminar11/tasks/task05_transactional -v
```

Все задачи и проверки стиля:

```bash
uv run pytest seminar11/tasks -v
uv run ruff check seminar11
uv run mypy seminar11
```

Заготовки вызывают `NotImplementedError`, поэтому до решения задач тесты
падают. Помимо результатов, проверяются порядок действий, метаданные,
независимость состояний и сохранение исходных объектов. Ограничения по
памяти и времени проверяются также при просмотре кода.

Установка окружения: `uv sync --extra test --extra lint`.
