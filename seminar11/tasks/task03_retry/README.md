# Задача 3. retry — 6/10

Загрузка записи может завершиться временной ошибкой. Напишите декоратор,
который повторяет вызов при указанных исключениях.

Реализуйте в `retry.py`:

```python
def retry(attempts: int, errors: tuple[type[Exception], ...]) -> RetryDecorator: ...
```

Готовый `RetryDecorator` описывает сохранение параметров и типа результата
функции. Дописывать его не нужно.

- `attempts` — **общее** максимальное число попыток, включая первую.
  При `attempts < 1` вызов фабрики сразу вызывает `ValueError`.
- `errors` — непустой кортеж классов исключений, наследников `Exception`.
  Пустой кортеж вызывает `ValueError` тоже при создании декоратора.
  Типы входных настроек соответствуют аннотациям.
- Исходная функция вызывается с теми же аргументами. Первый успешный
  результат сразу возвращается как есть, в том числе `None`, `False` или `0`.
- Если возникло одно из `errors` или его наследник, выполните следующую
  попытку, пока бюджет не закончился. После последней неудачи наружу уходит
  **то же самое последнее исключение**, без обёртки и замены.
- Любая неперечисленная ошибка сразу проходит наружу, даже если до неё
  уже были повторяемые ошибки. `KeyboardInterrupt` и другие исключения
  вне `Exception` не перехватываются настройкой `errors=(Exception,)`.
- Каждый вызов обёртки получает полный новый бюджет попыток. Несколько
  функций, украшенных одним созданным декоратором, независимы.
- Аргументы не копируются. Если неудачная попытка изменила переданный
  список, следующая увидит эти изменения. Отката побочных эффектов нет.
- Создание декоратора и декорирование не вызывают исходную функцию.
  Метаданные сохраняются по [общим требованиям](../../README.md#общие-требования).

Никаких задержек и сетевых запросов: повтор — обычный следующий вызов.
Не используйте готовые библиотеки повторов.

```python
calls = 0


@retry(attempts=3, errors=(TimeoutError,))
def load_record(record_id: int) -> str:
    global calls
    calls += 1
    if calls < 3:
        raise TimeoutError("попробуйте ещё раз")
    return f"запись {record_id}"


load_record(42)  # "запись 42"
calls  # 3
load_record(43)  # "запись 43" — успешная первая попытка нового вызова
calls  # 4

retry(0, (TimeoutError,))  # ValueError сразу, без декорируемой функции
```
