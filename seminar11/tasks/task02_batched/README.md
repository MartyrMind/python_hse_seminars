# Задача 2. batched — 6/10

Сервис цен принимает не больше ста идентификаторов за один запрос. Функция
загрузки уже умеет обрабатывать один пакет и возвращать список результатов.
Напишите декоратор, который разбивает входные данные на пакеты, вызывает
функцию для каждого пакета и объединяет ответы.

Реализуйте `batched(size: int) -> BatchDecorator` в `batched.py`.
Готовый `BatchDecorator` — только описание типов; его менять не нужно.

Исходная функция принимает первым позиционным аргументом `list[T]`, а
возвращает `list[R]`. Обёртка принимает на том же месте `Iterable[T]`.
Остальные параметры сохраняются.

- `size` — максимальный размер пакета. При `size <= 0` вызов
  `batched(size)` сразу вызывает `ValueError`, ещё до передачи функции.
  Размер дан целым числом.
- Вход конечен, может быть одноразовым генератором. Обойдите его один раз,
  сохраняя исходный порядок; собирать весь вход в коллекцию нельзя.
- Каждому вызову исходной функции передаётся **новый непустой список**
  длиной `size`. Только последний пакет может содержать меньше элементов.
  Элементы не копируются и остаются исходными объектами.
- Остальные позиционные и именованные аргументы передаются каждому вызову
  без изменений. Первый аргумент обёртки передаётся позиционно; имена вроде
  `items` могут одновременно встречаться в остальных именованных аргументах.
- Объедините возвращённые списки в один новый обычный список. Число
  результатов пакета не обязано равняться числу его входных элементов:
  обработчик может отфильтровать всё или вернуть несколько результатов.
- Пустой источник даёт `[]`, исходная функция не вызывается.
- Сначала соберите и обработайте текущий пакет, затем читайте следующий.
  Декорирование не читает источник и не вызывает исходную функцию.
- При ошибке обработчика немедленно передайте наружу то же исключение;
  следующий пакет читать нельзя. Уже выполненные операции не отменяются.
- Ошибки источника тоже проходят наружу. Если источник сломался при сборке
  очередного пакета, незавершённый пакет обработчику не передаётся.
- Метаданные сохраняются по [общим требованиям](../../README.md#общие-требования).
  Один созданный декоратор можно применять к нескольким функциям независимо.

Готовую функцию `itertools.batched` использовать нельзя. Память для входных
данных ограничена размером одного пакета; итоговый список хранится целиком.

```python
calls = []


@batched(size=2)
def load_prices(product_ids: list[int], *, currency: str = "RUB") -> list[str]:
    calls.append((product_ids, currency))
    return [f"{number}:{currency}" for number in product_ids]


load_prices(iter([10, 20, 30, 40, 50]), currency="EUR")
# ["10:EUR", "20:EUR", "30:EUR", "40:EUR", "50:EUR"]

calls
# [([10, 20], "EUR"), ([30, 40], "EUR"), ([50], "EUR")]

load_prices([])  # [] — нового вызова обработчика нет
```

Сетевые запросы не нужны: в тестах обработчиком будет обычная функция.
