# Задача 1. trimmed — 4/10

Функция возвращает заголовок отчёта с лишними пробелами по краям.
Напишите декоратор, который очищает её результат.

Реализуйте в `trimmed.py`:

```python
def trimmed[**P](func: Callable[P, str]) -> Callable[P, str]: ...
```

Декоратор возвращает обёртку, которая вызывает исходную функцию и удаляет
пробельные символы с обоих краёв полученной строки, включая табуляцию,
переводы строк и пробелы Unicode.

- Позиционные и именованные аргументы передаются без изменений.
- На один вызов обёртки приходится ровно один вызов исходной функции.
- Пробелы и переводы строк внутри текста остаются на месте. Пустая строка
  и строка из одних пробельных символов дают `""`.
- Декорирование само по себе функцию не запускает.
- Исключения исходной функции проходят наружу без замены.
- Метаданные сохраняются по [общим требованиям](../../README.md#общие-требования).

Исходная функция всегда возвращает строку, если завершается нормально.
Преобразовывать другие типы в строки не требуется.

```python
@trimmed
def greeting(name: str, *, punctuation: str = "!") -> str:
    """Поприветствовать."""
    return f"  Привет, {name}{punctuation} \n"


greeting("Аня")  # "Привет, Аня!"
greeting("Боря", punctuation="?")  # "Привет, Боря?"
greeting.__name__  # "greeting"
greeting.__doc__  # "Поприветствовать."
```
