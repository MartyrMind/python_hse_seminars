# Задача 5. transactional — 10/10

Несколько функций меняют словарь настроек. Если одна из них завершилась
с ошибкой, нужно отменить её изменения. Вложенная операция должна допускать
отдельный откат, после которого внешняя операция может продолжиться.

Реализуйте в `transactional.py`:

```python
class Transactions[K, V]:
    def __init__(self, state: dict[K, V]) -> None: ...
    def atomic(self) -> AbstractContextManager[dict[K, V]]: ...
    def transactional[**P, R](self, func: Callable[P, R]) -> Callable[P, R]: ...
```

`state` — обычный словарь. Объект хранит ссылку на него, а не подменяет копией.
Изменения выполняет пользовательский код внутри блока или функции.

## Контекстный менеджер

Каждый вызов `atomic()` создаёт новый одноразовый менеджер контекста.

- Через `as` выдаётся тот же объект `state`.
- При нормальном выходе изменения сохраняются.
- При любом исключении, включая наследников `BaseException`, восстановите
  состояние словаря на момент входа в блок: значения и порядок ключей.
  Добавленные ключи исчезают, удалённые возвращаются. Затем передайте
  наружу то же исключение без подавления.
- Изменения между созданием менеджера и входом в блок не отменяются.
- Восстанавливается **исходный объект** словаря. Существующие ссылки на него
  должны видеть восстановленное содержимое.

```python
settings = {"mode": "normal", "port": 80}
tx = Transactions(settings)

with tx.atomic() as current:
    current is settings  # True
    settings["port"] = 8080

settings  # {"mode": "normal", "port": 8080} — изменения приняты

try:
    with tx.atomic():
        settings["mode"] = "debug"
        settings["temporary"] = True
        raise ValueError("конфигурация не прошла проверку")
except ValueError:
    pass

settings  # {"mode": "normal", "port": 8080} — изменения отменены
```

## Вложенность

У каждого входа собственная точка сохранения.

- Ошибка внутреннего блока восстанавливает состояние на момент входа
  **в него**. Если внешняя операция поймала ошибку, она может продолжаться.
- Успех внутреннего блока сохраняет изменения в текущем словаре. Если
  позднее упадёт внешний блок, эти изменения тоже будут отменены.
- Если ошибка проходит через несколько уровней, каждый откатывается
  до состояния на момент входа в него. Число уровней заранее не фиксировано.

```python
settings = {"port": 80}
tx = Transactions(settings)

with tx.atomic():
    settings["port"] = 8080
    try:
        with tx.atomic():
            settings["port"] = -1
            raise ValueError("неверный порт")
    except ValueError:
        pass
    settings["port"]  # 8080 — отменён только внутренний блок

settings  # {"port": 8080}
```

## Декоратор

`@tx.transactional` выполняет каждый вызов функции внутри новой транзакции
с теми же правилами. Он передаёт все аргументы, возвращает исходный объект
результата. Метаданные сохраняются по
[общим требованиям](../../README.md#общие-требования). Декорирование не вызывает
функцию и не меняет словарь.

```python
@tx.transactional
def configure(port: int) -> int:
    settings["port"] = port
    if port < 0:
        raise ValueError("неверный порт")
    return port


configure(9000)  # 9000, settings теперь {"port": 9000}
# configure(-1) поднимет ValueError, settings останется {"port": 9000}
```

Контекстные менеджеры и украшенные функции могут вкладываться друг в друга,
в том числе при рекурсии. После ошибки объектом можно пользоваться дальше.
Менеджеры разных словарей независимы.

## Границы отката

Восстанавливаются ссылки на прежние значения. Если внутри блока изменили
вложенный список, его содержимое не откатывается. `None` не означает отсутствие
ключа. Побочные эффекты вне словаря — запись в файл, изменения другого
словаря — тоже не отменяются.
