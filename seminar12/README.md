# Семинар 12. Месяц маленькой кофейни

[Открыть ноутбук](Seminar12.ipynb). Занятие на 90 минут: 15 коротких заданий
на одном наборе данных, затем два дополнительных для тех, кто закончил раньше.
Ноутбук содержит объяснения, примеры, заготовки и проверки ответов.

## Подготовка

Из корня репозитория:

```bash
uv sync --extra notebook
```

Откройте `Seminar12.ipynb` в VS Code или Jupyter и выберите Python из `.venv`
репозитория. В набор зависимостей входит ядро `ipykernel`; отдельный сервер
Jupyter для работы в VS Code не требуется.

Готовые данные лежат в `data/`: 28 дней с 5 октября 2026 года, четыре напитка,
seed 42. Первая ячейка загрузки работает из корня репозитория и из `seminar12`.
Генерировать данные перед первым открытием не обязательно.

## Сюжет и маршрут

Помогаем владельцу кофейни возле кампуса разобраться в продажах и выручке.
Строка массива продаж — день, столбец — напиток. По мере работы из чисел
собирается отчёт с датами и названиями колонок.

| Время | Темы | Задания |
|---|---|---|
| 0–10 | Массив, форма, тип, поэлементная арифметика | 1 |
| 10–25 | Индексы, срезы, общая память и копирование | 2–3 |
| 25–40 | Булевы маски, отбор и подсчёт | 4–5 |
| 40–55 | Двумерные массивы, `axis`, средние, `argmax` | 6–8 |
| 55–65 | Broadcasting и выручка | 9–10 |
| 65–80 | DataFrame, Series, фильтрация, сортировка, новая колонка | 11–14 |
| 80–90 | Самостоятельный пересчёт при изменении цен | 15 |

Дополнительно: средняя выручка по будням и выходным (`groupby`) и применение
дневной скидки ко всей строке (`where`, `newaxis`). Примеры также показывают
разницу между `loc` и `iloc` после сортировки.

Студенты заменяют `...` в ячейках заданий и запускают проверки под ними.
До решения проверки падают. Задания идут последовательно: следующие
используют результаты предыдущих. При случайном изменении исходных данных
нужно перезапустить ядро и выполнить ячейки заново.

## Генератор данных

```bash
uv run python seminar12/generate_data.py --seed 42 --days 28
uv run python seminar12/generate_data.py --seed 17 --days 35 --start-date 2026-11-02
```

Без `--output-dir` скрипт записывает CSV в `data` рядом с собой независимо
от текущего каталога. Можно указать другую папку:

```bash
uv run python seminar12/generate_data.py --seed 99 --output-dir /tmp/coffee-99
```

Для использования такого варианта в ноутбуке поменяйте `data_dir` в ячейке
загрузки на этот путь. После замены CSV перезапустите ядро.

Скрипт работает на стандартной библиотеке Python. Одинаковые параметры
в том же окружении воспроизводят данные; другой seed меняет продажи.
Повторный запуск **перезаписывает** `sales.csv` и `prices.csv` в выбранной папке.

- `sales.csv`: дата и целочисленные неотрицательные продажи четырёх напитков.
- `prices.csv`: название напитка и его постоянная цена в рублях.

У напитков разный обычный спрос. Продажи колеблются по дням, по выходным
ожидаемый спрос выше, иногда отдельный напиток не покупают совсем. На коротком
случайном отрезке выходные могут оказаться слабее будней. Пропусков нет.
Цены фиксированы; генератор не моделирует реакцию спроса на изменение цен.

Число дней может быть любым положительным. Проверки в ноутбуке не привязаны
к seed, конкретным итогам, понедельнику в первой строке или наличию выходных.
