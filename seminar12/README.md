# Семинар 12. NumPy и Pandas

В [ноутбуке](Seminar12.ipynb) — 15 заданий и 2 дополнительных.
Данные: продажи четырёх напитков в кофейне за 28 дней.
Темы: массивы, срезы, маски, оси, broadcasting и работа с таблицами.

## Запуск

Из корня репозитория:

```bash
uv sync --extra notebook
```

Откройте `Seminar12.ipynb` в VS Code или Jupyter. Выберите ядро Python
из `.venv` репозитория.

Выполняйте ячейки по порядку. В заданиях заменяйте `...` своим кодом,
затем запускайте проверку под заданием. Если изменили исходные данные,
перезапустите ядро и выполните ячейки заново.

## Данные

Готовые CSV лежат в `data/`:

- `sales.csv` — дата и число проданных чашек каждого напитка;
- `prices.csv` — название напитка и цена в рублях.

Цены постоянны, пропусков нет. Ноль означает, что напиток в этот день не покупали.

## Генерация данных

Чтобы получить другой набор, выполните из корня репозитория:

```bash
uv run python seminar12/generate_data.py --seed 17 --days 28
```

`--seed` задаёт вариант, `--days` — положительное число дней.
При одинаковых параметрах данные повторяются.
Дополнительно можно задать `--start-date 2026-11-02` и `--output-dir /tmp/coffee`.

По умолчанию скрипт перезаписывает CSV в `seminar12/data/`.
После генерации перезапустите ядро ноутбука. Если указали другую папку,
задайте её путь в переменной `data_dir` в ячейке загрузки.
