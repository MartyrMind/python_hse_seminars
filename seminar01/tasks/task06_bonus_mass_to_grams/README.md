# Задача 6 (бонус). mass_to_grams

Масса записана в килограммах с точностью до грамма, например `"12,500"` или
`"1 234.056"`. Разделителем дробной части служит запятая либо точка, а пробелы
могут использоваться как разделители тысяч.

Реализуйте функцию `mass_to_grams(text: str) -> int`, возвращающую массу целым
числом граммов.

## Сигнатура

```python
def mass_to_grams(text: str) -> int: ...
```

## Примеры

```python
mass_to_grams("1 234,056")  # 1_234_056
mass_to_grams("12.500")     # 12_500
mass_to_grams("0007,005")   # 7_005
mass_to_grams("0,000")      # 0
```

Масса неотрицательна, целая часть присутствует, после разделителя всегда ровно
три цифры. Запись корректна — проверять её не нужно.

Нельзя преобразовывать строку во `float`: большинство десятичных дробей не
представимы в двоичной системе точно. Разберите целую и дробную части как
строки, а результат соберите целочисленной арифметикой. Задача решается без
циклов и условных операторов.
