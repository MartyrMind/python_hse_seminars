# Задача 1. seat_position

В кинозале места идут подряд: сначала все места первого ряда, затем второго и
так далее. Номера рядов и мест начинаются с единицы.

Реализуйте функцию
`seat_position(place: int, row_size: int) -> tuple[int, int, bool]`. Она должна
вернуть:

1. номер ряда;
2. номер места внутри ряда;
3. находится ли место с края ряда.

Крайними считаются первое и последнее места ряда. Если в ряду только одно
место, оно тоже крайнее.

## Сигнатура

```python
def seat_position(place: int, row_size: int) -> tuple[int, int, bool]: ...
```

## Примеры

```python
seat_position(1, 8)   # (1, 1, True)
seat_position(8, 8)   # (1, 8, True)
seat_position(17, 8)  # (3, 1, True)
seat_position(20, 8)  # (3, 4, False)
```

Оба аргумента — положительные целые числа. Проверять их корректность не нужно.
Задача решается без циклов и условных операторов.
