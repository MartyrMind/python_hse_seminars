# Задача 2. parse_build_tag

Система сборки помечает каждый результат строкой из трёх частей:

```text
язык / номер сборки / хеш коммита
```

Вокруг каждой части могут быть пробелы. Номер сборки записан десятичными
цифрами и может начинаться с нулей. Хеш содержит не меньше семи
шестнадцатеричных символов.

Реализуйте функцию `parse_build_tag(tag: str) -> tuple[str, int, str]`, которая
возвращает:

1. язык в верхнем регистре;
2. номер сборки как целое число;
3. первые семь символов хеша в нижнем регистре.

## Сигнатура

```python
def parse_build_tag(tag: str) -> tuple[str, int, str]: ...
```

## Примеры

```python
parse_build_tag(" python / 0314 / A1B2C3D4E5 ")
# ("PYTHON", 314, "a1b2c3d")

parse_build_tag("rust/42/1234567890")
# ("RUST", 42, "1234567")
```

Формат строки корректен, проверять его не нужно. Задача решается без циклов и
условных операторов.
