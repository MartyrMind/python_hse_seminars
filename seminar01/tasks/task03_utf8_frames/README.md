# Задача 3. utf8_frames

Текст передают по сети в кодировке UTF-8. Поток байт разбивается на кадры по
`frame_size` байт. Последний кадр при необходимости дополняется пустыми байтами.

Реализуйте функцию
`utf8_frames(text: str, frame_size: int) -> tuple[int, int, int, int]`, которая
возвращает четыре числа:

1. количество символов в исходной строке;
2. количество байт после кодирования в UTF-8;
3. количество кадров, необходимое для передачи;
4. количество незанятых байт в последнем кадре.

Для пустой строки кадров и незанятых байт нет.

## Сигнатура

```python
def utf8_frames(text: str, frame_size: int) -> tuple[int, int, int, int]: ...
```

## Примеры

```python
utf8_frames("hello", 4)   # (5, 5, 2, 3)
utf8_frames("привет", 4)  # (6, 12, 3, 0)
utf8_frames("", 4)        # (0, 0, 0, 0)
```

Размер кадра — положительное целое число. Проверять аргументы не нужно. Найдите
количество кадров арифметической формулой округления вверх, без циклов и
условных операторов. Пустая строка должна обработаться той же формулой.
