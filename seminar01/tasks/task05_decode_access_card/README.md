# Задача 5. decode_access_card

Пропуск сотрудника записан строкой из трёх частей:

```text
подразделение / номер сотрудника / байт состояния
```

Вокруг частей могут быть пробелы. Подразделение нужно нормализовать в верхний
регистр, номер сотрудника записан десятичными цифрами, а байт состояния — двумя
шестнадцатеричными цифрами.

В байте состояния используются следующие биты:

```text
бит:   7 6 5 4 | 3 2 1 | 0
      +--------+-------+--------+
      | прочее | доступ| активен|
      +--------+-------+--------+
```

- младший бит равен единице, если пропуск активен;
- следующие три бита задают уровень доступа от 0 до 7;
- старшие четыре бита в этой задаче игнорируются.

Реализуйте функцию
`decode_access_card(card: str) -> tuple[str, int, bool, int]`, возвращающую
подразделение, номер сотрудника, активность и уровень доступа.

## Сигнатура

```python
def decode_access_card(card: str) -> tuple[str, int, bool, int]: ...
```

## Примеры

```python
decode_access_card(" ami / 0042 / A5 ")  # ("AMI", 42, True, 2)
decode_access_card("rnd/0007/0E")        # ("RND", 7, False, 7)
decode_access_card("ops/0001/01")        # ("OPS", 1, True, 0)
```

Формат пропуска корректен, проверять его не нужно. Решение не требует циклов или
условных операторов.
