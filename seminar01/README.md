# Семинар 1. Базовые типы

Цель семинара — научиться проходить полный путь от условия задачи до зелёных
тестов и потренировать арифметику, строки, кодировки, преобразования типов и
битовые операции.

## Задачи

1. [`seat_position`](tasks/task01_seat_position/README.md) — целочисленное деление,
   остаток и логическое выражение.
2. [`parse_build_tag`](tasks/task02_parse_build_tag/README.md) — методы строк, срезы и
   преобразование к `int`.
3. [`utf8_frames`](tasks/task03_utf8_frames/README.md) — различие между символами и
   байтами.
4. [`packet_header`](tasks/task04_packet_header/README.md) — маски, сдвиги и упаковка
   нескольких чисел в одно.
5. [`decode_access_card`](tasks/task05_decode_access_card/README.md) — самостоятельная
   сборка изученных приёмов.
6. [`mass_to_grams`](tasks/task06_bonus_mass_to_grams/README.md) — бонус о точном разборе
   десятичных значений без `float`.
