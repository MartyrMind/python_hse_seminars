# Задача 4. route — 8/10

Редактор поездки хранит остановки по порядку. Пользователь добавляет их,
переставляет, заменяет и удаляет. У всех способов записи одно правило: название
остановки обрезается по краям от пробелов, а пустое название недопустимо.

Реализуйте класс `Route`, наследующийся от `collections.abc.MutableSequence[str]`.
В заготовке намеренно указано **только наследование**: обязательные методы
интерфейса найдите сами. Для работы нужны конструктор
`Route(stops: Iterable[str] = ())`, методы `__len__`, `__getitem__`,
`__setitem__`, `__delitem__`, `insert` и представление `__repr__`.

- Конструктор принимает любой итерируемый объект, включая генератор. Маршрут
  хранит собственные данные: изменение исходного списка не влияет на него.
- По целому индексу чтение, замена и удаление работают как у списка.
  Отрицательные индексы допустимы, выход за границы вызывает `IndexError`.
  Срезы в этой задаче не требуются.
- `insert(index, value)` вставляет остановку по правилам списка: слишком
  большой индекс означает конец, слишком маленький отрицательный — начало.
- Название нормализуется при создании, `insert` и замене по индексу.
  После `strip()` пустая строка вызывает `ValueError`.
- `__repr__` возвращает строку вида `Route(['Москва', 'Тверь'])`.

`MutableSequence` и её базовые классы предоставляют `append`, `extend`,
`pop`, `remove`, `reverse`, `index`, `count`, `__contains__`, `__iter__`,
`__reversed__` и другие операции. **Не реализуйте эти методы в `Route`**:
они должны быть унаследованы. Например, готовый `append` использует ваш
`insert`, поэтому правило нормализации действует и при вызове `append`.
Пока обязательные методы ABC отсутствуют, экземпляр `Route` создать нельзя.

```python
route = Route([" Москва ", "Тверь"])
list(route)                    # ["Москва", "Тверь"]
route.append(" Новгород ")
route[-1]                     # "Новгород"
route.index("Тверь")          # 1

route[0] = " Химки "
route.insert(1, " Клин ")
list(route)                    # ["Химки", "Клин", "Тверь", "Новгород"]

route.append("   ")           # ValueError
del route[0]
route.pop()                   # "Новгород"
repr(route)                   # "Route(['Клин', 'Тверь'])"
```
