# Задача 2. shuffle_deck — 6/10

Для карточной викторины используется класс `Deck` из чужой библиотеки. Его
определение уже дано в `enable_shuffle.py`: колода знает свой размер и умеет
отдавать карту по индексу. Этого хватает для чтения и перебора, но
`random.shuffle(deck)` не работает. Функция меняет элементы коллекции на месте,
а в `Deck` нет `__setitem__`.

Изменять определение `Deck` нельзя. Реализуйте `enable_shuffle() -> None` в том
же файле. При необходимости добавьте вспомогательную функцию **вне класса**.

- Вызов `enable_shuffle()` должен добавить `__setitem__` **к классу `Deck` во
  время выполнения**. Создавать новый класс или заменять `Deck` нельзя.
- После вызова должна работать запись `deck[index] = card`: карта по индексу
  заменяется, остальные не меняются. Отрицательные индексы и `IndexError` за
  границами работают как у списка.
- Изменение действует на все экземпляры `Deck`, в том числе созданные до
  вызова `enable_shuffle()`.
- После вызова `random.shuffle(deck)` перемешивает карты на месте, не теряя и
  не добавляя карты. `enable_shuffle()` ничего не возвращает.

Присвоить `__setitem__` одному объекту недостаточно: для синтаксиса
`deck[index] = card` Python ищет специальный метод в классе. Здесь нужно
изменить именно класс во время работы программы — сделать *monkey patch*.

```python
from random import Random

deck = Deck(["туз", "король", "дама", "валет"])
enable_shuffle()

deck[1] = "десятка"
list(deck)                     # ["туз", "десятка", "дама", "валет"]

Random(17).shuffle(deck)       # теперь работает
sorted(deck)                   # те же четыре карты
```

`Deck` хранит карты во внутреннем списке `_cards`. Сигнатуру и тело готовых
методов класса не меняйте.
