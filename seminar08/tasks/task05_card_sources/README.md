# Задача 5. card_sources — 9/10

Приложение для повторения материала выдаёт карточки в двух режимах. В режиме
стека первой выходит последняя добавленная карточка; в режиме очереди — первая
добавленная. Остальные действия у режимов одинаковые: загрузить несколько
карточек, проверить пустоту и взять сразу несколько.

В заготовке указаны только имена классов. Реализуйте собственный абстрактный
базовый класс `CardSource(ABC)` и его потомков `StackSource` и `QueueSource`.

В `CardSource` объявите три **абстрактных** метода через `@abstractmethod`:

- `put(card: str) -> None` добавляет одну карточку;
- `draw() -> str` удаляет и возвращает следующую карточку; на пустом источнике
  вызывает `LookupError`;
- `__len__() -> int` возвращает число карточек.

Там же реализуйте четыре **готовых** метода только через этот интерфейс, без
обращения к полям конкретных потомков:

- `load(cards: Iterable[str]) -> None` добавляет карточки в порядке перебора;
- `is_empty() -> bool` сообщает, пуст ли источник;
- `draw_many(count: int) -> list[str]` выдаёт `count` карточек по порядку.
  При `count < 0` вызывается `ValueError`. Если карточек меньше, вызывается
  `LookupError` **до удаления первой карточки**. При `count == 0` возвращается
  пустой список без изменения источника;
- `__call__() -> str` делает то же, что `draw()`, чтобы источник можно было
  вызвать как функцию.

Оба потомка принимают в конструкторе `cards: Iterable[str] = ()` и хранят
собственные карточки. `StackSource` выдаёт последнюю добавленную, `QueueSource`
— первую. Текст карточек не нормализуется: допустима любая строка.
Готовые методы из `CardSource` **не переопределяйте** в потомках. Класс
`CardSource` и потомок, не реализовавший хотя бы один абстрактный метод,
не должны создавать экземпляры.

```python
stack = StackSource(["A", "B", "C"])
stack.draw_many(2)             # ["C", "B"]
stack()                        # "A"
stack.is_empty()               # True

queue = QueueSource(["A", "B", "C"])
queue.draw_many(2)             # ["A", "B"]
queue.draw()                   # "C"

queue.load(card for card in ["D", "E"])
queue.draw()                   # "D"
queue.draw_many(3)             # LookupError; карточка "E" остаётся
```
