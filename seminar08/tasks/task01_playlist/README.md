# Задача 1. playlist — 5/10

Музыкальный плеер хранит треки в заданном порядке. Для прослушивания нужен
плейлист, который можно узнать по длине, прочитать по индексу и перебрать в
цикле. При этом специальный метод `__iter__` писать не требуется: Python умеет
перебирать объект через последовательные вызовы `__getitem__` с индексами
`0, 1, 2, ...`, пока не получит `IndexError`.

Реализуйте класс `Playlist` в файле `playlist.py`.

- `Playlist(tracks: list[str])` сохраняет копию списка. Изменение исходного
  списка после создания плейлиста не должно менять плейлист.
- `__len__` возвращает число треков.
- `__getitem__` по целому индексу возвращает трек. Отрицательные индексы
  работают как у списка; выход за границы вызывает `IndexError`.
- `__getitem__` по срезу возвращает **новый `Playlist`**, а не список. Срез
  может содержать шаг, включая отрицательный. Срезы обрабатываются по
  обычным правилам списка.
- `__contains__` проверяет, есть ли трек с точно таким названием **без учёта
  регистра**. Используйте сравнение через `str.casefold()`; пробелы и части
  названия отдельно не обрабатывайте. Для аргумента, который не является
  строкой, возвращайте `False`.
- `__repr__` возвращает строку вида `Playlist(['Intro', 'Outro'])`.

Не наследуйтесь от ABC и не определяйте `__iter__` и `__reversed__`. Цикл `for`
и `reversed()` должны работать благодаря `__len__` и `__getitem__`. Для пустого
плейлиста `__getitem__(0)` обязан вызвать `IndexError`, иначе перебор не
закончится. `__contains__` здесь написан явно, потому что поиск без учёта
регистра отличается от обычного сравнения строк.

```python
tracks = ["Intro", "Verse", "Outro"]
playlist = Playlist(tracks)

len(playlist)                   # 3
playlist[0]                    # "Intro"
playlist[-1]                   # "Outro"
playlist[1:]                   # Playlist(['Verse', 'Outro'])
playlist[::-1]                 # Playlist(['Outro', 'Verse', 'Intro'])
list(playlist)                 # ["Intro", "Verse", "Outro"]
list(reversed(playlist))       # ["Outro", "Verse", "Intro"]
"intro" in playlist            # True
42 in playlist                 # False
playlist[3]                   # IndexError

tracks.append("Bonus")
list(playlist)                 # ["Intro", "Verse", "Outro"]
```
