# Семинар 2. Управляющие конструкции

На семинаре последовательно разберём ветвления, циклы, списковые включения,
сопоставление с образцом, обработку последовательностей и чтение файлов.

## Задачи

1. [`delivery_quote`](tasks/task01_delivery_quote/README.md) — условия и
   форматирование.
2. [`digital_root_steps`](tasks/task02_digital_root_steps/README.md) — цикл
   `while` и изменение состояния.
3. [`analyze_scores`](tasks/task03_analyze_scores/README.md) — списковое
   включение, `any` и `all`.
4. [`walk_robot`](tasks/task04_walk_robot/README.md) — разбор команд через
   `match`.
5. [`longest_plateau`](tasks/task05_longest_plateau/README.md) — один проход
   по последовательности.
6. [`pack_batches`](tasks/task06_pack_batches/README.md) — жадное накопление
   групп.
7. [`cashflow_stats`](tasks/task07_cashflow_stats/README.md) — работа с
   текстовым файлом.
8. [`render_multiplication_table`](tasks/task08_bonus_render_multiplication_table/README.md)
   — бонус на вложенные циклы и выравнивание.
9. [`shift_digits`](tasks/task09_bonus_shift_digits/README.md) — бонус на
   `ord`, `chr` и циклический сдвиг.
