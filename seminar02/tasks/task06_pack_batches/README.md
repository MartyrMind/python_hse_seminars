# Задача 6. pack_batches

Предметы поступают на упаковку в заданном порядке. Их нужно последовательно
раскладывать по коробкам вместимости `capacity`:

- очередной предмет кладётся в текущую коробку, если после этого суммарный вес
  не превышает вместимость;
- иначе текущая коробка закрывается, а предмет становится первым в новой;
- менять порядок предметов нельзя.

Такой алгоритм называется жадным: решение для очередного предмета принимается
сразу, без перестановки оставшихся.

Реализуйте функцию
`pack_batches(weights: list[int], capacity: int) -> list[list[int]]`,
возвращающую содержимое коробок.

## Сигнатура

```python
def pack_batches(weights: list[int], capacity: int) -> list[list[int]]: ...
```

## Примеры

```python
pack_batches([4, 3, 5, 2, 2], 7)  # [[4, 3], [5, 2], [2]]
pack_batches([2, 3, 5], 10)       # [[2, 3, 5]]
pack_batches([5, 1, 4], 5)        # [[5], [1, 4]]
pack_batches([], 10)              # []
```

Все веса положительны и не превышают `capacity`; вместимость положительна.
Проверять аргументы не нужно. Пустых коробок в результате быть не должно.
