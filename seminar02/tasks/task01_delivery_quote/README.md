# Задача 1. delivery_quote

Служба доставки использует три тарифа:

| Масса посылки | Обычная доставка |
|---|---:|
| не больше 1 кг | 200 ₽ |
| больше 1 кг, но не больше 5 кг | 350 ₽ |
| больше 5 кг | 350 ₽ + 50 ₽ за каждый килограмм сверх 5 |

Дополнительная масса учитывается точно: например, посылка массой 5.5 кг стоит
375 ₽. Экспресс-доставка увеличивает итоговую стоимость в полтора раза.

Реализуйте функцию `delivery_quote(weight: float, express: bool) -> str`,
которая возвращает строку `"Доставка: <стоимость> ₽"`. Стоимость должна быть
напечатана ровно с двумя знаками после точки.

## Сигнатура

```python
def delivery_quote(weight: float, express: bool) -> str: ...
```

## Примеры

```python
delivery_quote(0.5, False)  # "Доставка: 200.00 ₽"
delivery_quote(5.0, False)  # "Доставка: 350.00 ₽"
delivery_quote(7.0, False)  # "Доставка: 450.00 ₽"
delivery_quote(7.0, True)   # "Доставка: 675.00 ₽"
```

Масса положительна, проверять аргументы не нужно.
