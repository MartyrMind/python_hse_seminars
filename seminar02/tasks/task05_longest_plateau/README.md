# Задача 5. longest_plateau

Плато последовательности — максимальная группа подряд идущих равных значений.
Например, в списке `[1, 1, 2, 2, 2, 1]` три плато: длины 2, 3 и 1.

Реализуйте функцию
`longest_plateau(values: list[int]) -> tuple[int, int]`, возвращающую индекс
начала самого длинного плато и его длину. Если максимальную длину имеют
несколько плато, выберите первое. Для пустого списка верните `(-1, 0)`.

## Сигнатура

```python
def longest_plateau(values: list[int]) -> tuple[int, int]: ...
```

## Примеры

```python
longest_plateau([1, 1, 2, 2, 2, 1])  # (2, 3)
longest_plateau([7, 7, 1, 1])        # (0, 2)
longest_plateau([5])                 # (0, 1)
longest_plateau([])                  # (-1, 0)
```

Решение должно делать один проход по списку и не создавать его копию. Во время
прохода храните информацию о текущем плато и о лучшем найденном плато.
