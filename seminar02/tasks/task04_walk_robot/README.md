# Задача 4. walk_robot

Робот начинает в точке `(0, 0)` и получает последовательность текстовых
команд. Распознаются следующие формы:

| Команда | Действие |
|---|---|
| `up N` | увеличить `y` на `N` |
| `down N` | уменьшить `y` на `N` |
| `right N` | увеличить `x` на `N` |
| `left N` | уменьшить `x` на `N` |
| `pause` | перейти к следующей команде |
| `stop` | прекратить обработку |
| любая другая форма | проигнорировать |

Слова могут быть разделены несколькими пробельными символами. Направления
записаны в нижнем регистре, расстояния — неотрицательные целые числа.

Реализуйте функцию
`walk_robot(commands: list[str]) -> tuple[int, int, int]`, возвращающую
координаты `x`, `y` и количество выполненных команд перемещения.

## Сигнатура

```python
def walk_robot(commands: list[str]) -> tuple[int, int, int]: ...
```

## Примеры

```python
walk_robot(["right 3", "up 2", "left 1"])  # (2, 2, 3)
walk_robot(["right 4", "stop", "up 100"])  # (4, 0, 1)
walk_robot(["pause", "jump 5", "up 2"])    # (0, 2, 1)
```

Разбирайте результат `command.split()` оператором `match`. Для `pause` и
неизвестных команд используйте `continue`, для `stop` — `break`.
