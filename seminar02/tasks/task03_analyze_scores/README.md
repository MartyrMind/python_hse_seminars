# Задача 3. analyze_scores

В списке находятся результаты проверочной работы. Корректная оценка лежит от 0
до 10 включительно, проходная — от 4 до 10 включительно. Из-за ошибки импорта в
списке могут встретиться числа вне допустимого диапазона.

Реализуйте функцию
`analyze_scores(scores: list[int]) -> tuple[list[int], bool, bool]`, которая
возвращает:

1. список корректных проходных оценок с сохранением порядка;
2. есть ли среди результатов хотя бы одна десятка;
3. корректны ли все значения исходного списка.

## Сигнатура

```python
def analyze_scores(scores: list[int]) -> tuple[list[int], bool, bool]: ...
```

## Примеры

```python
analyze_scores([3, 4, 10])   # ([4, 10], True, True)
analyze_scores([12, -1, 7])  # ([7], False, False)
analyze_scores([])           # ([], False, True)
```

Пустой список не содержит десятки, но все его элементы корректны: именно так
определены `any` и `all`. Первый результат получите списковым включением,
второй — через `any`, третий — через `all`.
