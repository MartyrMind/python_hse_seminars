# Задача 7. cashflow_stats

В текстовом файле записаны операции по счёту:

```text
# сентябрь
+ 1000
- 250

+ 75
STOP
+ 500
```

Каждая операция состоит из знака `+` или `-` и неотрицательной целой суммы.
Пустые строки и строки, которые после удаления пробелов начинаются с `#`,
игнорируются. Строка `STOP` прекращает обработку; всё после неё не учитывается.

Реализуйте функцию
`cashflow_stats(path: str) -> tuple[int, int, int, int]`, которая читает файл
в UTF-8 и возвращает:

1. количество учтённых операций;
2. сумму поступлений;
3. сумму расходов как положительное число;
4. итоговый баланс: поступления минус расходы.

## Сигнатура

```python
def cashflow_stats(path: str) -> tuple[int, int, int, int]: ...
```

Для показанного файла ответ равен `(3, 1075, 250, 825)`: последняя операция
расположена после `STOP` и не учитывается.

Файл существует, а все его значимые строки имеют корректный формат. Файл может
быть большим, поэтому обрабатывайте его построчно внутри `with open(...)`, не
используя `read` или `readlines`.
