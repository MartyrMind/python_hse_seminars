# Семинар 5. Функции и первые классы

Цель семинара — потренировать передачу аргументов, работу с функциями как
объектами, полями класса и экземпляра и обычными методами.

Каждая задача соответствует оценке, которую можно получить за семинар. Задачи
можно решать независимо, их сложность постепенно возрастает.

## Задачи

1. **5/10 — [`invoke`](tasks/task01_invoke/README.md):** вызвать функцию
   с переданными аргументами.
2. **6/10 — [`rank_items`](tasks/task02_rank_items/README.md):** отобрать
   и упорядочить элементы с помощью переданных функций.
3. **7/10 — [`event_log`](tasks/task03_event_log/README.md):** реализовать
   журнал с общей настройкой и отдельной историей для каждого экземпляра.
4. **8/10 — [`make_dispatcher`](tasks/task04_make_dispatcher/README.md):**
   создать функцию для вызова команд по имени.
5. **9/10 — [`task_queue`](tasks/task05_task_queue/README.md):** реализовать
   очередь отложенных вызовов.
6. **10/10 — [`bind_call`](tasks/task06_bind_call/README.md):** сопоставить
   аргументы вызова с параметрами функции.

## Проверка

```bash
uv run pytest seminar05/tasks -v
```

Пока задачи не решены, тесты завершаются с `NotImplementedError`. Реализуйте
выбранные функции и методы в их файлах и запустите тесты соответствующего
каталога.
