# Задача 4. make_dispatcher — 8/10

Напишите `make_dispatcher(commands)`, которая получает таблицу команд
и возвращает функцию для их вызова по имени. У команды может быть несколько
имён: например, `"ls"` может ссылаться на `"list"`.

## Сигнатуры

```python
def make_dispatcher(commands): ...


# Возвращаемая функция:
def dispatch(name, /, *args, **kwargs): ...
```

Ключи `commands` — строки. Значение — функция, связанный метод или строка
с именем другой команды. Строковое значение называется псевдонимом.

## Требования

- `dispatch` находит команду по имени. Если это псевдоним, поиск продолжается
  по указанному имени. Цепочка может состоять из нескольких псевдонимов.
- Найденная функция вызывается ровно один раз с переданными аргументами.
  Её результат возвращается без копирования; аргументы тоже не копируются.
- Если имени нет в таблице или цепочка зациклилась, вернуть `None`,
  ничего не вызывая. Аргументы такого вызова игнорируются.
- `make_dispatcher` не вызывает команды.
- Таблица фиксируется при создании диспетчера: изменения исходного словаря
  не влияют ни на команды, ни на псевдонимы. Функции и экземпляры связанных
  методов остаются исходными объектами.
- Диспетчер можно вызывать многократно. Создание другого диспетчера не меняет
  уже существующий.

Для найденной функции аргументы корректны. Пустая строка допустима как имя
команды и как цель псевдонима.

## Обязательные приёмы

Верните вложенную функцию с заданной сигнатурой. Для выбора команды используйте
словарь. Глобальные переменные, классы-диспетчеры, `eval`, `exec` и готовые
библиотечные обёртки использовать нельзя.

## Примеры

```python
commands = {"length": len, "size": "length", "n": "size", "text": str}
dispatch = make_dispatcher(commands)

dispatch("n", [1, 2, 3])  # 3
dispatch("text", 7)  # "7"
dispatch("missing")  # None

commands.clear()
dispatch("size", [1, 2])  # 2
```

```python
dispatch = make_dispatcher({"a": "b", "b": "a", "broken": "missing"})
dispatch("a")  # None
dispatch("broken")  # None
```

Имя команды передаётся отдельно от аргументов её функции:

```python
def greet(*, name):
    return f"Привет, {name}"


dispatch = make_dispatcher({"hello": greet, "hi": "hello"})
dispatch("hi", name="Анна")  # "Привет, Анна"
```
