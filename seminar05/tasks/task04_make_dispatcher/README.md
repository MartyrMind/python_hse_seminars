# Задача 4. make_dispatcher — 8/10

Напишите `make_dispatcher(commands)`, которая получает словарь функций
и возвращает функцию для их вызова по имени.

## Сигнатуры

```python
def make_dispatcher(commands): ...


# Возвращаемая функция:
def dispatch(name, /, *args, **kwargs): ...
```

Ключи `commands` — строки, значения — функции или связанные методы.
Например, словарь `{"length": len, "text": str}` задаёт две команды.

## Требования

- `dispatch` находит команду по `name`, вызывает её ровно один раз с переданными
  аргументами и возвращает результат. Аргументы и результат не копируются.
- Если имени нет в таблице, возвращается `None`; ничего не вызывается.
- `make_dispatcher` не вызывает команды — они выполняются только при
  последующих вызовах `dispatch`.
- Таблица команд фиксируется при создании диспетчера: изменения исходного
  словаря на него не влияют. Самих функций и экземпляров, с которыми связаны
  методы, это не касается — должны использоваться исходные объекты.
- Диспетчер можно вызывать многократно. Создание другого диспетчера не меняет
  уже существующий.

Для известной команды аргументы корректны. Для неизвестной они игнорируются.

## Обязательные приёмы

Верните вложенную функцию с заданной сигнатурой. Для выбора команды используйте
словарь функций. Глобальные переменные, классы-диспетчеры, `eval`, `exec`
и готовые библиотечные обёртки использовать нельзя.

## Примеры

```python
commands = {"length": len, "text": str}
dispatch = make_dispatcher(commands)

dispatch("length", [1, 2, 3])  # 3
dispatch("text", 7)  # "7"
dispatch("missing")  # None

commands.clear()
dispatch("text", 8)  # "8"
```

Имя команды передаётся отдельно от аргументов её функции:

```python
def greet(*, name):
    return f"Привет, {name}"


dispatch = make_dispatcher({"hello": greet})
dispatch("hello", name="Анна")  # "Привет, Анна"
```
