# Задача 1. invoke — 5/10

Реализуйте функцию `invoke`, которая вызывает переданную функцию `func`
с указанными аргументами и возвращает её результат.

## Сигнатура

```python
def invoke(func, /, *args, **kwargs): ...
```

## Требования

- `func` вызывается ровно один раз.
- Все аргументы передаются без изменений и копирования.
- Возвращается тот же объект, который вернула `func`, в том числе `None`.
- В качестве `func` может быть передана функция или связанный метод.

Аргументы соответствуют сигнатуре `func`; проверять их не нужно.

## Обязательные приёмы

Сохраните сигнатуру и используйте распаковку аргументов.
`eval`, `exec` и готовые библиотечные обёртки использовать нельзя.

## Примеры

```python
def calculate(x, /, *, scale=1):
    return x * scale


invoke(calculate, 3, scale=4)  # 12
invoke(len, [])  # 0
invoke(list)  # []
```

Аргумент с именем `func` тоже должен дойти до вызываемой функции:

```python
def describe(*, func):
    return f"Обработчик: {func}"


invoke(describe, func="report")  # "Обработчик: report"
```

```python
items = []
invoke(items.append, 7)  # None
items  # [7]
```
