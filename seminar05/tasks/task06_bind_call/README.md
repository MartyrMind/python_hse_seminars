# Задача 6. bind_call — 10/10

Реализуйте `bind_call`: по описанию параметров функции и аргументам её вызова
определите, какое значение получит каждый параметр.

## Сигнатура

```python
def bind_call(parameters, defaults, args, kwargs): ...
```

## Входные данные

`parameters` — список пар «имя, вид» в порядке объявления параметров:

| Вид | Что обозначает | Пример |
|---|---|---|
| `"p"` | только позиционный параметр | `x` в `def f(x, /)` |
| `"n"` | позиционный или именованный параметр | `x` в `def f(x)` |
| `"a"` | оставшиеся позиционные аргументы | `args` в `def f(*args)` |
| `"k"` | только именованный параметр | `x` в `def f(*, x)` |
| `"v"` | оставшиеся именованные аргументы | `kwargs` в `def f(**kwargs)` |

`defaults` — словарь значений по умолчанию. `args` — кортеж переданных
позиционных аргументов, `kwargs` — словарь именованных.

Например, для `def f(x, /, y=2, *rest, flag=False, **extra)`:

```python
parameters = [("x", "p"), ("y", "n"), ("rest", "a"), ("flag", "k"), ("extra", "v")]
defaults = {"y": 2, "flag": False}
```

Описание соответствует допустимой сигнатуре Python: имена уникальны,
параметры расположены в правильном порядке. Любой из видов может отсутствовать,
весь список может быть пустым. Умолчания бывают только у `p`, `n` и `k`.

Вызов тоже корректен: аргументов хватает, ни один параметр не заполняется
дважды, для лишних аргументов предусмотрены `*args` или `**kwargs`.
Обнаруживать ошибки вызова не нужно.

## Результат

Верните новый словарь «имя параметра — значение». Ключи идут в порядке
объявления параметров. Параметру `a` соответствует кортеж, параметру `v` —
словарь, в том числе пустые, если лишних аргументов нет.

- Связывание должно соответствовать правилам вызова функций Python.
- Входные списки и словари не изменяются. Словарь для `v` должен быть новым
  и сохранять исходный порядок оставшихся именованных аргументов.
- Значения аргументов и умолчаний не копируются.

## Обязательные приёмы

Используйте циклы и встроенные контейнеры. Нельзя использовать `inspect`,
`eval`, `exec`, генерировать функции или делегировать связывание библиотеке.

## Примеры

Для `parameters` и `defaults` из примера выше:

```python
bind_call(parameters, defaults, (1, 3, 4), {"flag": True, "mode": "fast"})
# {"x": 1, "y": 3, "rest": (4,), "flag": True, "extra": {"mode": "fast"}}

bind_call(parameters, defaults, (1,), {})
# {"x": 1, "y": 2, "rest": (), "flag": False, "extra": {}}
```

Имя параметра до `/` может встретиться и среди именованных аргументов:

```python
# def f(x=10, /, **extra)
bind_call([("x", "p"), ("extra", "v")], {"x": 10}, (), {"x": 20})
# {"x": 10, "extra": {"x": 20}}
```

Пример с `*args` и `**kwargs`:

```python
# def f(*args, **kwargs)
bind_call([("args", "a"), ("kwargs", "v")], {}, (1,), {"args": 2, "kwargs": 3})
# {"args": (1,), "kwargs": {"args": 2, "kwargs": 3}}
```
