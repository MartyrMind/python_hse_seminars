# Задача 5. task_queue — 9/10

Реализуйте очередь вызовов функций: `submit` добавляет вызов в очередь,
`run_all` выполняет накопленные вызовы.

## Интерфейс

```python
class TaskQueue:
    def __init__(self): ...
    def submit(self, func, /, *args, **kwargs): ...
    def run_all(self): ...
```

## Требования

- Каждая очередь изначально пуста и работает независимо от других.
- `submit` принимает функцию и её аргументы, ничего не вызывает и возвращает `None`.
- `run_all` выполняет вызовы в порядке добавления, каждый ровно один раз,
  и возвращает новый список результатов. Результаты `None` тоже входят в список.
- Выполненные вызовы удаляются из очереди. Для пустой очереди результат — `[]`.
- Если во время выполнения функция добавляет новые вызовы в эту же очередь,
  они остаются до следующего `run_all`.
- Аргументы, функции и экземпляры связанных методов не копируются. Если объект
  аргумента изменился между `submit` и `run_all`, функция увидит новое состояние.

Все вызовы корректны и завершаются успешно. Выполняемая функция может делать
`submit`, но не вызывает `run_all` и не меняет внутренние поля очереди напрямую.

## Обязательные приёмы

Используйте обычный класс с `__init__` и методами, сохранив сигнатуры.
Храните функции и аргументы как объекты Python; при вызове используйте распаковку.
Готовые библиотечные очереди, `eval`, `exec` и `deepcopy` использовать нельзя.

## Примеры

```python
queue = TaskQueue()
items = []
queue.submit(items.append, 7)
queue.submit(len, items)
items  # []

queue.run_all()  # [None, 1]
items  # [7]
queue.run_all()  # []
```

Замена значения в словаре, распакованном при `submit`, и изменение самого
переданного объекта дают разные результаты:

```python
values = [1]
options = {"items": values}
queue.submit(dict, **options)

options["items"] = [99]
values.append(2)
queue.run_all()  # [{"items": [1, 2]}]
```

Вызов, добавленный во время выполнения, ждёт следующего запуска:

```python
def schedule():
    queue.submit(str, 42)
    return "запланировано"


queue.submit(schedule)
queue.run_all()  # ["запланировано"]
queue.run_all()  # ["42"]
```
