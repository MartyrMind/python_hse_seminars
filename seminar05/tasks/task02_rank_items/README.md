# Задача 2. rank_items — 6/10

Реализуйте функцию `rank_items`: отберите элементы списка по условию `accept`
и упорядочьте их по значению `score`.

## Сигнатура

```python
def rank_items(items, /, *, score, accept=None, reverse=True): ...
```

- `items` — список объектов.
- `accept(item)` возвращает `True`, если элемент нужно оставить.
  При `accept=None` остаются все элементы.
- `score(item)` возвращает целое число, по которому сравниваются элементы.
- `reverse=True` задаёт порядок по убыванию, `False` — по возрастанию.

## Требования

Верните новый список. Исходный список не меняется; сами элементы не копируются.
При равных значениях `score` сохраняется исходный порядок элементов.

Порядок вызовов тоже важен:

- сначала `accept`, если он задан, вызывается для каждого элемента слева направо;
- после завершения отбора `score` вызывается для каждого оставленного элемента,
  также в исходном порядке;
- каждая функция вызывается один раз на соответствующее вхождение элемента,
  даже если один объект встречается в списке несколько раз.

Переданные функции не меняют список и его элементы. Пустой список, нулевые
и отрицательные значения `score` допустимы.

## Обязательные приёмы

Сохраните сигнатуру. Используйте переданные функции и встроенную сортировку
с параметром `key`. Нельзя заменять переданные функции проверками их имён
или типов элементов.

## Примеры

```python
def long_enough(word):
    return len(word) >= 2


rank_items(["a", "bbb", "cc", "dd"], score=len, accept=long_enough)
# ["bbb", "cc", "dd"]

rank_items(["bbb", "a", "cc"], score=len, reverse=False)
# ["a", "cc", "bbb"]

rank_items([], score=len)
# []
```

В первом примере `accept` вызывается четыре раза, а `score` — три:
для `"bbb"`, `"cc"` и `"dd"`. Слова `"cc"` и `"dd"` имеют одинаковую длину
и остаются в исходном порядке.
