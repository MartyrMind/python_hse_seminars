# Задача 2. rank_items — 6/10

Участников нужно расположить по убыванию баллов, а при равных баллах — по
возрастанию числа попыток. В другой таблице критерии могут быть другими.

Реализуйте `rank_items`: отберите элементы по условию `accept` и упорядочьте
их по переданному списку критериев.

## Сигнатура

```python
def rank_items(items, /, *, criteria, accept=None): ...
```

- `items` — список объектов.
- `criteria` — список пар `(score, reverse)` в порядке важности.
  `score(item)` возвращает целое число. `reverse=True` означает порядок
  по убыванию, `False` — по возрастанию.
- `accept(item)` возвращает `True`, если элемент нужно оставить.
  При `accept=None` остаются все элементы.

## Требования

Первый критерий — основной. Второй применяется при равенстве по первому,
третий — при равенстве по первым двум, и так далее. Если все значения равны,
исходный порядок сохраняется. При пустом `criteria` сохраняется порядок
элементов после отбора.

Результат — новый список. Исходный список и список критериев не меняются;
сами элементы не копируются.

Если задан `accept`, он вызывается один раз для каждого вхождения элемента,
слева направо. Отбор завершается до вычисления критериев. Каждый критерий
вызывается ровно один раз для каждого оставленного вхождения. Порядок этих
вызовов после отбора не задан.

Переданные функции не меняют входные данные. Значения критериев могут быть
нулевыми и отрицательными; пустой список допустим.

## Обязательные приёмы

Сохраните сигнатуру. Используйте переданные функции и встроенную сортировку
с параметром `key`. Не заменяйте переданные критерии проверками их имён
или типов элементов.

## Примеры

```python
def points(row):
    return row[1]


def attempts(row):
    return row[2]


rows = [("А", 8, 1), ("Б", 10, 3), ("В", 10, 1), ("Г", 8, 2)]

rank_items(rows, criteria=[(points, True), (attempts, False)])
# [("В", 10, 1), ("Б", 10, 3), ("А", 8, 1), ("Г", 8, 2)]

rank_items(rows, criteria=[(attempts, False), (points, True)])
# [("В", 10, 1), ("А", 8, 1), ("Г", 8, 2), ("Б", 10, 3)]
```

```python
def long_enough(word):
    return len(word) >= 2


rank_items(["a", "bbb", "cc", "dd"], criteria=[(len, True)], accept=long_enough)
# ["bbb", "cc", "dd"]

rank_items(["bbb", "a", "cc"], criteria=[], accept=long_enough)
# ["bbb", "cc"]
```
