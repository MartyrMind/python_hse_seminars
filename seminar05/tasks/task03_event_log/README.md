# Задача 3. event_log — 7/10

Реализуйте класс `EventLog` — журнал сообщений. У каждого журнала своя история
записей. Перед сообщением добавляется префикс, по умолчанию `"INFO"`.

## Методы

- `EventLog(initial=None)` — создать журнал. `initial` — список готовых записей;
  без него история пуста. Изменения переданного списка не должны менять журнал,
  а изменения журнала — переданный список.
- `add(message)` — добавить строку `"[префикс] сообщение"` и вернуть её.
- `snapshot()` — вернуть отдельный список всех записей. Его изменение
  не влияет на журнал; новые записи в журнале не меняют прежний снимок.

## Префикс

Поле класса `EventLog.prefix` изначально равно `"INFO"`.
Присваивание `EventLog.prefix = "DEBUG"` меняет префикс у всех журналов,
включая уже созданные.

Исключение — журналы с индивидуальной настройкой `log.prefix = "LOCAL"`.
У них сохраняется собственный префикс независимо от изменений поля класса.

Новый префикс применяется только к новым сообщениям. Прежние записи и строки
из `initial` не переформатируются. Пустые префикс и сообщение допустимы.

## Обязательные приёмы

Используйте обычный класс, `__init__` и методы. Сохраните поле класса `prefix`
и сигнатуру конструктора. История должна храниться в списке.
Свойства, наследование и глобальное хранилище журналов использовать нельзя.

## Примеры

```python
first, second = EventLog(), EventLog()
first.add("старт")  # "[INFO] старт"
second.snapshot()  # []

EventLog.prefix = "DEBUG"
first.add("загрузка")  # "[DEBUG] загрузка"

first.prefix = "LOCAL"
EventLog.prefix = "ERROR"
first.add("нет файла")  # "[LOCAL] нет файла"
second.add("нет файла")  # "[ERROR] нет файла"

first.snapshot()
# ["[INFO] старт", "[DEBUG] загрузка", "[LOCAL] нет файла"]
```

```python
log = EventLog(["старая запись"])
saved = log.snapshot()
saved.clear()
log.snapshot()  # ["старая запись"]
```
